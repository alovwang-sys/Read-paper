# 从 AI 推荐收录研究资料

2026-10-17。对应 issue #3 的首个用户主动收录切片。资料收录和取得全文分别完成：下载失败不撤销已保存的文献或链接。实际检查、截图及公网冒烟结果见[验收记录](../verification/source-intake/README.md)。

## 用户路径

AI 完成回答后，显式 HTTP(S) 链接、DOI 和 arXiv 标识汇总为“回答中的资料”。普通聊天不自动收录。用户可直接“加入本研究”，或“查看文献”后判断。仅打开预览不会创建文献实体，不扩大 AI 上下文；来源预览在所属中央窗格中打开独立标签，可多开与分屏，右侧对话、输入和其他窗格保留。

点击加入后，先保存条目及研究关联，保存成功才返回收录回执；后台随后补元数据并尝试获取全文。收录成功后留在原来源预览，显示已加入及“打开资料”，由用户主动打开；从聊天直接加入也保留主区。重复加入复用已知标识或同一文件，研究之间共用实体。

| 结果 | 界面与下一步 |
| --- | --- |
| 取得 PDF | 全文可读；用户明确打开后阅读 |
| 仅有书目信息或原摘要 | 已收录、暂无全文；原摘要显示获取来源 |
| 信息读取失败 | 保留链接和推荐标题；可编辑信息、重试或手动补全文 |
| 全文下载失败 | 保留资料及摘要，说明原因，提供重试和原网页 |
| 保存条目失败 | 显示保存失败，保留输入与恢复缓冲，可重试；不启动全文下载 |
| PDF 已属于另一条资料 | 不覆盖或静默合并；预览影响，确认后转移关联和收录记录 |

无全文条目依然是正常资料。作者摘要、AI 推荐说明和用户的收录备注分别表达。摘要只能来自明确的原站摘要字段、arXiv 或 Crossref；站点 description 不冒充论文摘要。信息未取得不构造作者、年份或页码。首轮摘要仅供查看，PDF 摘录、问 AI 和页级证据仍沿用现有显式材料规则。

后续可在原条目选择或拖入 PDF。正常补全文保留文献 ID、研究关联和白板位置；重复文件确认合并时保留已有全文实体 ID。拖到窗口其他位置仍为普通导入。已有全文不能通过本入口换版本，避免旧摘录改指来源。

## 数据和归属

沿用 schema 3，使用可选字段向后兼容，旧 PDF/条目/证据不转换身份。加载时校验新增字段；上次未完成的全文获取转为可重试的中断状态，重开页面不会擅自重复下载。

- `PaperDocument` 保存共享书目、可追溯的原摘要、来源类型、PDF 线索和获取状态；原文件仍通过 hash 与资产 ID 固定。
- `Research.sourceRecords[documentId]` 保存本研究的收录备注及发现记录；记录原链接、会话、消息和推荐段落快照。同一论文用于多个研究时理由分别保存。
- `WorkspaceTab.preview` 随研究布局保存候选及发现信息；`Session.sourcePreview` 仅投影当前聚焦预览，兼容既有调用。`documentInfoId` 在同一文献视图内切换信息和阅读。
- 原始 AI 回答保持不变，发现记录不等于支持卡片的原文证据。用户手改字段或补齐全文后，迟到结果不能覆盖。
- 研究切换不改变已提交任务目标；整库恢复或重载使旧任务失效。合并转移研究关联、白板、标签和收录记录；移出研究不删除全局原文件。

## 服务和安全边界

沿用现有本机 Node 服务，无需新端口、模型密钥或新依赖。

| 接口 | 输入与输出 |
| --- | --- |
| `POST /api/sources/resolve` | `{url}` → 标准来源候选；元数据不可获取时保留可收录的最小信息与原因 |
| `POST /api/sources/pdf` | `{url}` → PDF 二进制，失败为 JSON `{error}` |

优先使用 DOI 的 Crossref 记录、arXiv Atom/摘要页，再读取公开网页 citation/OG/title 元数据。明确 PDF 链接在下载时校验；网页正文快照不在本轮范围。显式 arXiv 版本保留在来源和下载地址中，文献标识与文件版本分开。

两个接口先通过现有受信 Host/Origin/桌面 token 检查。远程获取逐跳检查 HTTP(S) 地址与 DNS，固定已校验地址建立连接，拒绝内网、保留地址、凭据和非标准端口。元数据上限 2 MiB，全文 50 MiB；校验超时、重定向、大小和 PDF 内容，再由现有 PDF.js 导入验证、hash 去重与持久化。获取不到登录或付费内容时保留条目，让用户自行从原站获取并补文件。

PDF 阅读器显式使用随 `pdfjs-dist` 打包的解码器。Vite 开发和构建均提供 `/pdfjs/wasm/` 及其许可证；桌面协议保持正确 MIME，CSP 仅增加 WASM 编译权限。真实文献中使用 JBIG2 等编码的页面也能在本地渲染。

浏览器运行 `npm run dev` 和 `npm run ai`；Vite 开发与预览均代理 `/api/sources`。改前端端口时同步 `AI_APP_PORT`。Electron 使用相同处理器、精确协议白名单及打包服务文件，不另设数据主库。

桌面退出先完成工作区保存确认，再取消应用发起的助手探测、能力和原生记录查询，并等待本机服务结束；模型设置切换与退出按顺序完成。已发起的全文获取也随本机服务停止而取消，重开后以中断状态供用户重试。

## 本轮范围

交付推荐链接收录、可选预览、元数据与原摘要、尝试取得 PDF、失败保留、手动补全文，以及研究独立的发现记录。既有“添加资料”粘贴链接入口复用同一服务。

不增加 Agent 自动批量收集、浏览器扩展、任意网页正文阅读、登录代办、定时追踪或跨版本证据迁移。用户授权本次加入不意味着自动发送整篇资料给 AI。页面切换不会停止已发起的获取，关闭整个应用或刷新会中断；未取得入库回执的服务端临时结果不冒充已保存。
