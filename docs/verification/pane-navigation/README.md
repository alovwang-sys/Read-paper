中央采用一套标签与菜单，去掉废弃第二套标签、重复路径、底部说明及空态口号。导航和普通打开遵循所属窗格，预览采用明确动作；自身边缘固定另开，跨组拖动移动。正文和文件共享，查看位置独立，关闭／收拢可恢复。窄列表重排标题、元数据与操作，保留正常字号。完整规则见[多窗格说明](../../panes/README.md)。
