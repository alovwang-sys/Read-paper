## 实际调整

- 右侧标题与模式切换合并，固定顶部从 108px 减为 46px；保留返回、固定、关闭和调宽。
- AI 会话标题、连接状态和工具区减少间距；原生记录刷新并入连接状态行。
- 本轮材料默认折叠，常显数量及首条资料名称；展开后核对论文、PDF 页码、原文及移除入口。原文列表最大高度从 130px 增至 220px，字体从 10–11px 调为 12px。
- 目录继承、前序历史和详细发送范围集中在“对话范围”。本机助手的累计上下文及授权目录能力仍可检查，材料选择和请求契约不变。
- 初始输入框从 86px 减为 56px，可手动调高；材料、助手、权限、技能、Chat/Plan、模型、推理强度、语音和发送/停止继续保留。
- 生成白板与修改已有白板入口并列；展开目标选择后仍能核对本次目标和范围。
