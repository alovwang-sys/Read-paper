## 已实现的用户路径

1. 在当前项目名称旁点击“…”进入“项目设置”，浏览本机已有目录或输入绝对路径，预览项目名称后点击“使用这个目录”。取消不改名、不写项目关联、不清空输入；原有论文和卡片不移动。
2. 打开 AI 并新建对话，原生 cwd 使用绑定目录；每轮显式证据另存不可变材料文件。旧临时目录的会话保留只读，用户明确开始项目内新对话。
3. 打开“对话记录”，搜索标题或已读取问答、按三种助手筛选，点击整行只读取历史。按原生身份归并，同名记录不混淆，同一记录不重复列出；归档与改名保留本软件语义。
4. 当前会话显示原生来源和原有上下文说明；刷新只读历史，不重执行模型或工具。有效论文引用继续在中央定位，右侧回答、输入与草稿保留。
5. 已知外部忙碌禁发且不能由本软件停止；未知状态按各适配器的实际保护能力处理。停止无法确认会持久保留只读限制，明确新建不会覆盖旧记录。

目录与历史失败均保留已看到的记录和未发送输入。部分 Agent 列表失败不遮住其他列表。新增外部正文只更新同一原生身份的显示缓存；软件原始回答的不可改写保护与卡片独立来源快照仍有效。

## 存储与恢复职责

| 位置 | 当前保存内容 | 恢复边界 |
| --- | --- | --- |
| 研究目录 `.read-paper/` | `project.json` 项目标识；`materials/<摘要>/manifest.json` 和 `materials.md`；`request-*.json` 请求/完成结果；`conversation-*.json` 已读原生历史的可读归档 | JSON 临时文件加 rename；归档失败单独说明。没有完整 PDF/图片资产与整个浏览器数据库 |
| 各厂商原生存储 | 原生会话日志、原生身份与认证 | 原生续接受运行时版本、认证、存储及占用保护限制，未搬动原有记录 |
| 浏览器 IndexedDB / localStorage | 论文与区域资产、证据、卡片、白板、结论、对话显示缓存及恢复缓冲 | 仍是研究业务数据来源；绑定目录不自动备份或迁移 |
| 桌面应用资料目录 `agents/`；网页 `AI_AGENT_STATE_DIR` | 服务端项目 binding、原生会话引用和映射 registry | 桌面使用稳定私有目录；网页未设置时沿用本机临时状态目录。单独复制项目目录不足以重建全部映射 |

已整合 main 的工作区 ZIP 备份/恢复，可保全 PDF、区域图片、研究业务数据和聊天显示缓存。P08 的项目目录独立恢复与厂商原生映射恢复仍未完成；ZIP 不包含服务端索引、外部原生历史或认证。`.read-paper` 可读归档不等于原生恢复点，也不承诺跨电脑继续相同原生身份。项目内不保存登录密钥。

## 确定性检查

整合 main `ff4b944` 后已通过：TypeScript 检查、生产构建、121 项单元测试、129 项服务端测试、16 项桌面边界测试、15 项发布保护测试，以及全部 54 项网页 E2E。最后的输入保留与原生读取时限修复另复跑 14 项相关网页路径通过。页面测试包含 7 项项目会话新增路径及既有阅读、白板、结论、备份、助手与技能回归；可控响应不声明真实模型已经回复。构建仍有既有主包体积提示，沿用 main 的依赖。

真实 macOS arm64 打包应用全部 6 项桌面 E2E 通过（main 既有 5 项＋新项目路径 1 项）：验证模型设置、保存/恢复与关闭行为，及无模型密钥下的目录取消/绑定、真实项目接口、列表、草稿和重启恢复。新路径隔离 HOME 与原生配置，不读取个人历史，`/chat` 与 `/agents/run` 请求均为 0。该结果证明 Papertrail 桌面集成，不代表 Codex、OpenCode、Claude Code 的完整模型往返。

桌面代理精确放行已实现的 AI/Agent/项目接口，主服务先校验私有 token；包中包含全部运行时模块，状态放在应用私有目录。原生读取设置整次 12 秒时限并中止自有读取连接，超时保留旧记录。打包期间仅修正验证命令的参数传递，随后使用同版本官方 Electron ZIP 缓存与官方 checksum 校验完成最终包；未修改依赖或永久配置，包中 70 个运行文件与源码/dist 的 hash 全部一致，见[构建记录与逐文件证据](../../../.sisyphus/incidents/2026-10-17-desktop-package-input-type/record.md)。

主 agent 另在应用内浏览器用真实本机服务创建独立的“项目会话验收（自制测试）”研究：目录预览后取消仍为待选择；再次确认后显示已连接；对话记录真实发现生产探针的 Codex 会话，读取到同一原生用户问题；返回历史和刷新页面后，目录、原生身份及未发送输入均保留。未从这个界面追加模型请求，未使用个人论文。没有可见回答的原生轮次明确显示未完成，不标“回答完成”。
