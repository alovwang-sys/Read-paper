# 普通聊天图片真实冒烟

本目录只验证新增普通图片的后端链路：真实 HTTP 请求 → `createResearchHandler` 校验 → 本轮隔离目录内的 `chat-image-1.png`、`chat-image-2.png` → 真实本机 Codex `localImage` → 流式回答。

2026-10-21 单轮真实调用成功，用时 117.168 秒，9 项检查全部通过。模型按顺序识别了红色矩形与蓝色圆形，实际生成收到 2 个有序字节一致的本地图片文件；正常完成，工具调用、PDF 读页和成果提交均为 0。输入图已实际打开核对，结果文件的敏感字段和路径扫描通过。

`probe.mjs` 使用 Node 标准库生成两张合法 PNG：图 1 是白底红色矩形，图 2 是白底蓝色圆形。问题与文件名不提供颜色、形状答案，要求模型按输入顺序辨认。发送的 `sources`、`history` 为空，不连接应用工作区或写入资料库。两张输入也保存在本目录，便于对照。

只允许一次真实生成。脚本先以 `wx` 创建 `result.json` 哨兵；文件存在即拒绝再次执行，不会自动重试。HTTP 请求总截止为 170 秒，另留清理时间，总预算 180 秒。结果仅保存图片元数据、临时文件名、顺序 hash 对照、应用已过滤的回答、布尔检查与模型名；不保存 base64、私有路径、原生 session ID、认证信息或私有推理。

运行命令（已存在结果时不要重复执行）：

```sh
node docs/verification/chat-inputs/live-image/probe.mjs
```

实际结果以 [result.json](result.json) 为准。此冒烟不代替图片上传、粘贴、预览、失败恢复、备份和桌面打包的界面验证，也不证明 Claude Code／OpenCode 已接图片研究工具或复杂图表识别可靠性。
