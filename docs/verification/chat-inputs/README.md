## 现在如何使用

- **图片**：点击输入框底部图片按钮，或直接粘贴、拖入 PNG／JPEG／WebP。最多四张、每张 8 MiB，白板图片选区也占一张；上传前后均检查原始格式、大小和 hash，不压缩或改图。可预览、移除，也可不输入文字直接发送。PDF 拖入继续原有资料导入路径。
- **语音**：点击“语音”，焦点留在输入框。macOS 桌面请求系统听写；浏览器与其他平台按提示使用系统听写快捷键。识别后的文字成为普通草稿，确认后再发送。此入口不包含应用内录音、音频文件上传或转写服务。
- **能力范围**：默认研究 Agent 当前只有 Codex 接了图片研究链路，所选模型还需确认支持图片。未支持时保留图文并阻止发送，没有把图片悄悄降级成文件名。Claude Code／OpenCode／模型直连与经典工作台的原有能力保留，不将本次新增入口算作其他供应商已接通。
- **会话与上下文**：图片只属于添加时的会话；提交时冻结原图引用，失败可恢复、重试用当轮原图，后来输入的新内容与新图保留。后续轮次默认只重放历史文字，不自动重发旧图片像素；需要再次看原图时应重新明确附图。普通图片不会自动形成 PDF 证据、扩大论文授权或导入资料库。
- **保存**：原图作为不可变本地资产保存；草稿、请求快照只存引用。刷新、退出重启、ZIP 备份与研究目录保存包括相应图片。损坏或缺失会明确报错，不以空附件继续发送；研究目录只归档该研究的资产。移除草稿图片保留历史资产，暂不新增孤立资产回收器。

## 本机能力检测修复

真实生成能看图，但最后实测旧能力探针10.759秒后返回 `ready / images:false`，同时目录的图片能力却为真。独立只读计时发现登录状态与首次模型目录查询已接近十秒；旧探针的十秒截止和吞异常会造成误判，进而让 UI 禁止上传。现复用同次模型目录，图片探测采用20秒预算、HTTP外层22秒；只有确认为图片不支持才返回不支持，协议错误／超时保留检测错误以便重试。增加模型目录复用和配置读取失败的服务回归。修后真实只读探测1.701秒返回 `ready / images:true`；没有再生成模型。
