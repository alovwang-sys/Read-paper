## Excalidraw 仍在使用

项目仍锁定 `@excalidraw/excalidraw` 0.18.1，`BoardDrawing` 直接渲染本地组件，不依赖把网页嵌入工作台。研究白板的“绘图”入口、卡片与 PDF 的共享摆放、自由手绘、文字、箭头、图片、保存与历史仍然存在。

独立运行既有浏览器用例，覆盖：

- 卡片／PDF 与手绘形状双向箭头、透明形状内部吸附、端点跟随、刷新、删除与撤销／重做。
- 卡片布局移动后返回绘图，同一摆放实例和连接同步；不复制一份新卡片。
- 框选后“问 Agent”，真实导出 PNG 和所选文字／卡片正文；不会把选区外节点或其他会话内容追加进去。无图能力时明确阻止，只有有效文字才允许用户选择文字模式。
- 失败重试使用原快照；停止、刷新、切换会话与迟到响应保持原请求归属。
- 绘图、资料与右侧原文／AI 在 1440×900、1280×800、1024×800 共存，唯一研究输入可达，无整页横向溢出。
- 绘图历史、模式和视口恢复、同板分栏的单一编辑者交接。

## 语音的真实能力

现有 `VoiceInput` 是**系统听写入口**。打开时先聚焦当前文本草稿，macOS 桌面经受限 IPC 发送固定 `startDictation:`；浏览器及其他平台显示操作系统快捷键。系统是否弹出录音授权、是否实际开始听写和识别效果，由操作系统配置与环境决定，调用成功只表示已派发请求。

识别文字留在草稿，用户自己发送。组件不调用 `getUserMedia`，不启用录音上传，不实现应用内录音转写服务，也不是直接把一段音频交给研究 Agent。

本轮现有经典 AI 面板的 **4 项听写浏览器用例通过**，覆盖无桥接、已请求、不可用和异常；验证聚焦、草稿保留、无自动发送、不请求录音。**4 项桌面桥接单元检查通过**，包括来源／主框架／聚焦检查和固定无参数 IPC。本目录没有验默认研究聊天的新入口，后续集成需另做验证。没有真实识别录音，不能宣称真实语音识别已通过。
