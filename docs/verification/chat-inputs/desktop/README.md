# 默认研究聊天图片 · 打包桌面验证

2026-10-21。使用本项目本地产生的 macOS arm64 应用，以临时 `PAPERTRAIL_USER_DATA`、`HOME` 和各供应商配置目录启动；清空模型密钥环境变量。研究请求全部受控拦截，不使用用户安装的应用或用户研究，不触发真实听写／录音，也不调用真实模型。

新增 `tests/desktop/chat-inputs.spec.ts` 通过实际按钮与文件选择器操作，验证：

- 默认聊天可见“添加图片”和“语音”入口；PNG、JPEG、WebP 可预览，纯图片可提交。
- HTTP 请求中的图片原字节与选择的文件逐张一致，空白新研究的请求未追加 PDF。
- 请求开始后旧附件被消费；执行期间继续添加新图与新问题。受控失败后这些新草稿保留，重试继续使用第一轮冻结的原始图片与历史。
- 退出应用后重启，已发送图片与回复、新图与未发送文字均恢复；直接只读隔离 IndexedDB 资产，确认三张历史图仍为原始字节。
- 页面运行错误为 0；测试不点击语音按钮，不能作为真实听写识别已通过的证据。

[checks.json](checks.json) 保存文件格式、字节数、SHA-256、请求数和命令结果。[重启后截图](desktop-images-after-restart-1440.png) 已实际打开复核；隔离环境没有真实 Codex 配置，重启后能力提示会明确保留附件并阻止未知能力发送，这不是本轮受控图片处理失败。

最终包（含 PDF 拖入兼容修复和本机图片能力探测修复）的新图片用例 **1/1 通过（8.1 秒）**，结果保存在 `checks.json`，对应打包记录 `/tmp/chat-inputs-package-probe-final.log`。能力探测修复前的同项结果另保留在 `checks-before-probe-fix.json`。先前打包产物的集成复跑 **2/2 通过（7.3 秒）**（`checks-initial-package.json`），同时复核旧 `agent-regressions` 的长消息、完整回复、文献入库和草稿重启路径；旧测试改写的截图已备份恢复，本轮结果另存 [桌面回归截图](desktop-long-message-regression-1440.png)。

新测试首次运行在最后的资产读回探针处失败：`fetch(blob:)` 被桌面现有 CSP 拦截，图片已经正常显示且前续发送、重试、重启断言已通过。只修改新测试，改为读取隔离资产仓库，没有放宽产品 CSP。完整复跑通过；原始失败 trace 保留在本机 `/tmp/papertrail-chat-inputs-desktop-tests/`。
