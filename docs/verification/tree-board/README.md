# 树形白板与已有图补充草稿验收

2026-10-20。此前代码先提交为 `7f55041`，本轮在 `codex/research-map-structure` 继续开发。本文记录源码和隔离测试；已安装的 Papertrail 仍为此前 0.1.10，未用源码检查冒充安装验收。

## 完成的用户路径

- 旧自由图通过预览确认进入层级整理。大纲可上移/下移、调整归属、提升一级、添加子节点/同级节点；布局按实际父级与顺序计算。退出层级模式为完整卡片留出间距，自由分组背景与连线共用实际卡片尺寸。
- 根主题、分支和具体卡片有层级及图标区分，标题/摘要密度可切换。全文沿用右侧编辑器，多来源可选择；折叠、选择、搜索定位和视口按窗格保存。
- 父子曲线表达结构，语义关联独立、默认隐藏、可按需显示。语义线遇到第三张卡片时绕行；隐藏分支不改写真实关系端点。
- 当前聊天助手可在明确允许补卡的已有图中提出方法、评估计划和待验证问题。只使用提交时显式选中的原文材料；新增草稿与已有结构改动先预览、确认后应用，原卡正文不覆盖。
- 层级、顺序、布局与历史同批保存。普通移出节点保留其子节点并连续提升；整枝移出明确确认，卡片实体仍保留。历史副本重建父节点引用，同序节点重分配 ID 后仍保持预览顺序。导入、备份及服务请求拒绝跨板父级、循环和无效顺序。

没有增加依赖或另一套 AI 编排；复用当前助手、共享卡片、右侧面板、持久化和历史服务。旧数据不从语义连线猜父子关系。

## 真实 Codex 与页面

单次真实 Codex 请求耗时 **157.309 秒**，没有整轮生成截止计时或重试。自然短句要求补充已有图的方法、运行条件和评估计划，未规定节点数量与布局。结果保留 3 张旧卡的身份、归属和顺序，新增 8 张草稿，共 **11 个节点、10 条父子关系、6 条语义关联**。新增内容逐段区分依据、建议与待确认，没有虚构已完成实验或数值阈值。

输入为合成材料；原始输入、原始回答、模型与回合信息、生产解析和人工内容复核在 [真实调用记录](../research-map/ai-existing-map/codex-probe.json)、[原始回答](../research-map/ai-existing-map/raw-response.txt)、[内容核查](../research-map/ai-existing-map/content-review.json)。一例通过不等于任意复杂研究图都可靠，也不是与之前新建图测试的受控 A/B 对比。

原样输出通过生产代码回放，三个窗口尺寸保持 100% 缩放和 14–15px 标题。实测零卡片重叠，每条路径采样 799 点未穿过第三张卡片；这些是本例近似测量。默认 7/11 张卡片完整可见，收起无关分支后 1440 下完整可见 6/6，1280/1024 下为 5/6，其余通过滚动读取。全文可在右侧查看。

## 保留的边界

- 树中通过大纲控件调整结构；分支拖放、手写、附属批注、PDF 摘录直接选目标分支、自动跟随回源未实施。
- 全部跨分支关系同时打开仍可能密集；手动重叠的自由卡片及被覆盖的端点不保证自动避让。80 节点布局与 160 边几何有程序测试，但本轮没有同规模真实模型/UI 压力验收。
- 没有修改整轮原生生成/连接锁逻辑，没有验证独立 Codex 桌面与产品的实时双向接管。
- 本轮未重新打包安装、未推送远程、未更改真实研究资料。
