# 原文旁问答与内置 Pi 验收

日期：2026-10-19。对应 [issue #17](https://github.com/alovwang-sys/Read-paper/issues/17) 的首个实现切片。内置运行时与就地问答已接入；知识搜索和用户自定义技能仍未实现，不能将整个 issue 标记完成。本轮已完成三尺寸浏览器路径和相关集成检查，记录如下。设计依据见[交互参考与验收规则](interaction-references.md)。

## 实际行为

- 选择 PDF 文字、框选区域或点击已有摘录后，操作条出现在所选内容附近。“解释这段”明确提交解释请求；“提问”打开原文旁输入框，输入发送前不调用模型，单纯选择也不发送。
- 解释、继续追问、引用定位、停止、失败重试都在原文旁完成。材料详情显示所选内容及 PDF 页码；区域问答要求模型明确启用图片能力。
- 就地问答使用独立会话和显式材料，不自动带入右侧材料、历史或未发送输入，不自动出现在右侧历史列表。临时证据沿用现有对象，使用 `contextOnly` 避免仅为提问就新增摘录条目。
- “收为卡片”建立可编辑草稿，在浮窗中修改标题与正文，确认“保存卡片”后入库；卡片保留原文证据及问答来源。关闭不会丢弃问答或草稿；阅读器的“上次提问”可重新打开，已有实体沿用本地持久化。
- “在右侧继续”标记并打开同一会话，不复制问答；原右侧会话、材料和输入继续保留。右侧承担多材料比较、长讨论等任务。

## 共享运行时与范围

`server/pi-runtime.mjs` 使用 `@earendil-works/pi-agent-core@1.3.0` 的真实 `Agent`，通过 Pi 生命周期发送文本增量、管理本轮消息。自定义 `streamFn` 桥接既有模型传输，保留严格 SSE 完成检查、部分回答、图片、超时、取消、脱敏和无自动重试；输出送达前不继续读取下一段上游内容。

原文旁和右侧的模型连接都走 `/api/ai/chat`，共用模型、API 地址与服务端凭据，默认模型仍为 `glm-5.3-flash`。`/api/ai/config` 实际返回 `runtime: "pi"`、`tools: []`。无需用户另外安装 Pi 或 CLI；内置的是 Agent 运行能力，模型由已配置服务提供。演示模式继续明确标示；外部 Codex、Claude Code 和 OpenCode 仍为可选连接，使用各自已有配置和权限。

当前 Pi 没有联网搜索、shell、任意文件读取或用户自定义技能工具，不自动加载全局 Pi 配置或技能。卡片整理与修订仍走原有草稿和引用校验，不自动改写既有正文。后续工具扩展需另做实现与验收。

## 目录保存故障

本轮通过针对性测试复现两项失败，原始日志位于 [复现日志](directory-repro.log)：

1. 合法的多 MB PDF 在重复分组 base64 正则校验中触发 `RangeError: Maximum call stack size exceeded`，导致目录保存失败。校验已改为不含重复分组的字符与格式检查，并继续校验规范编码、内容 hash、资产和总量上限。
2. 研究目录写入的文件系统错误被通用 Agent 错误路径转成“本机 Agent 连接失败，请检查 CLI 配置后重试”。现在权限、只读磁盘、磁盘空间、配额及 I/O 故障分别使用存储原因提示，并明确应用内资料保留。

相关服务回归 113/113 通过，日志位于 [回归日志](directory-regression.log)；整体服务测试也通过。原有外部修改冲突、符号链接保护、事务恢复与重试保持有效。本轮未清理用户目录或重写历史文件；真实环境的其他权限、磁盘和外部编辑问题仍需按实际错误处理。

## 桌面浮窗消失回归

实际 IAB 与打包桌面发现：浮窗首次挂载时尚未 fixed，会占据页面文档流，引发宽度变化，阅读器因而清掉选区。已在初始隐藏状态就使用 fixed 定位；修复前桌面专项失败，修复后真实鼠标划选和退出重启通过。此问题只在实际有窗口的环境复现，不能仅凭无界面浏览器测试判断。桌面截图：[回答](desktop-answer-1440.png)、[重启恢复](desktop-restored-1440.png)。

## 真实模型冒烟

实际使用现有配置经 `/api/ai/chat` 和内置 Pi 请求 `glm-5.3-flash`，供应商返回 HTTP 429，错误为 `rate_limited`（额度或并发受限），没有收到回答，`completed: false`。结果见[机器记录](model-smoke.json)。

本轮只能确认真实调用返回了限流状态及可恢复错误；不能宣称 GLM 解释、追问、图片或存卡的真实模型链路成功，也不自动重试付费调用。
