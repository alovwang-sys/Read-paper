## 实际视觉问题

画布为 2200×2310，节点范围为 x=50–2010、y=80–2095。没有卡片矩形彼此重叠，但有以下问题：

1. 四个语义分组之间出现五对矩形区域重叠。前三组在左上角的标题也互相覆盖，画面看起来像许多卡片都属于最后绘制的“评估与验证计划”。`flow` 按所有关系求层级，却又用同名卡片的外接矩形画分组，两者并不保证分组互斥。
2. 27 条线中有 18 条穿过至少一张无关卡片，共 33 个“线—第三张卡片”命中。每条曲线按 399 个点采样统计，不是精确几何证明；截图也能看到连线被无关卡片截断。当前路由只考虑两个端点，未避让中间卡片。
3. 13/18 张卡片正文因现有四行摘要显示而截断。完整内容可在右侧查看，但画面没有为“依据 / 建议 / 待验证”提供不同的节点展示；全部仍显示“观点卡片”。
4. 缩小只能降低所有文字尺寸，不能把正文折叠为语义摘要，也没有分支收起。正常窗口的全局阅读与局部阅读之间缺少有效切换。

## 验证边界

此回放直接把生产 parser/preview 输出注入隔离的共享数据 fixture，**未覆盖真实发送、自动应用、历史写入**的完整链路。8 段来源是合成文本，没有对应 PDF；文档只创建元数据记录，未伪造 PDF 资产或借用其他论文。因此未测试原文跳转，也不能据此声称来源文件校验通过。

本次不改生产代码。树形父子关系、分支折叠、大纲同步均仍未实现。后续设计应把主结构与跨组关联分开，并由布局器管理分组、间距与避障；不能要求模型仅靠多写提示词保证像素级图面质量。
