# 左侧导航层级修复

本页保留功能分支阶段的验证结论；聊天、绘图和导航截图已在最新 main 回归时重拍，完整集成检查与平台边界见[集成验收](../main-integration/README.md)。

日期：2026-10-20。用户指出绘图截图中的左栏层级异常。本次修复现有导航，不实施仍待评审的整体导航与笔记整合方案。

## 原因与修复

`.research-nav .nav-item` 的优先级高于 `.nested-nav`，将具体白板和文稿的左缩进从 40px 覆盖为 15px；子项原先也没有类型图标。结果是具体条目的文字反而比父入口靠左，难以识别父子关系。这是既有样式缺陷，未发现 Excalidraw 样式泄漏。

现将子项规则限定为 `.research-nav .nested-nav`，恢复 40px 缩进；复用既有资源图标，父入口 13px、子项 12px，图标不压缩。长名称省略并通过标题提示显示全名。入口、共享数据、打开项与研究状态沿用原实现。

## 验证

```sh
npm run check
npx playwright test tests/e2e/navigation.spec.ts tests/e2e/drawing.spec.ts --output=/tmp/papertrail-navigation-fixed
npm run build
```

类型检查与生产构建通过（保留已有大 chunk 提示）；浏览器 **7 项通过，33.0 秒**。导航用例在三种尺寸实际核对图标与文字位置，确保子项向右缩进；验证父入口打开集合、子入口打开资源及选中状态、长标题省略、刷新恢复与 1024px 抽屉关闭。绘图 4 项回归同时通过，覆盖右侧 AI/原文、保存、历史及研究切换。
