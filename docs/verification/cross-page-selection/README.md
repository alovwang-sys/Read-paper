## 实现与数据保护

- 文字、区域都可从一页拖到另一页，支持正向、反向及阅读区上下边缘自动滚动。拖动经过的页面保持渲染，完成选区后继续保留相关页面，取消后恢复普通虚拟化。
- 一次选择关联一组单页证据：每页保留 `pageIndex`、文字锚点或区域坐标及图片；通过可选的 `selectionGroupId` 关联。区域仅截实际页内交集，排除 24px 页间间隙。原有单页证据、引用编号和快照结构继续可用。
- 同一个菜单可保存全部片段、制作一张含所有来源的卡片、提问、翻译或整理摘要；问答的 `contextIds` 与 `inlineSource.evidenceIds` 保留完整范围。提问、翻译、摘要仍是独立会话操作，模型产出继续为可编辑草稿。
- 菜单、问答和证据来源显示页范围，提供逐页定位；刷新可重开同组文字或多张截图。摘录撤销先检查整组引用，整组标记移除／恢复不会删除问答或卡片。
- 文字等待范围内所有页面文本终态；慢页保留选区，空文字／失败页明确提示并阻止保存缺页内容，可重试或取消。跨页复制仅复制各页文字，排除操作标记的数字；保留原生 Shift 点击扩选。同段原文已有多条标记时，点击明确回查的来源优先使用该来源，避免误操作另一研究的重叠标记。
- 图片超过当前单次上限（现有连接最多 4 张）时提示并保留选择，仍可保存摘录或手工制卡。重复保存同一区域复用资产，避免额外积累图片。异步保存回到原研究和选区版本检查；取消或切研究后旧操作不弹回旧错误。
- 新选区不覆写重叠旧选区；同一资料在不同研究中使用不同证据组。恢复校验拒绝同组重复页、混合文字／区域、跨文献／研究或缺失的问答来源。

[白板改名与列表点击专项](../board-title-and-list/README.md)覆盖保存失败、输入保留、刷新、研究切换、菜单、键盘和拖拽。[讨论分组专项](../discussion-groups/README.md)覆盖按来源与研究保存开合、搜索临时展开及恢复、显式重开与新回答不强制展开。
