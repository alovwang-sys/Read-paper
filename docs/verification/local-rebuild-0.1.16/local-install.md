旧版正常退出被“研究文件路径、内容或SHA-256无效”阻止，界面明确提示应用内资料已保存；这是 `6de5141` 已修复、旧安装尚未包含的绘图导出校验问题。旧版没有跳过目录保存的正常退出入口。
