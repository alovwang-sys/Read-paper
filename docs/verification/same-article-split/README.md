# 同篇文章直接分屏修复

2026-10-18，基线 `3ebb015`，随 PR #15 更新。修复前，同一窗格的唯一文章标签直接拖向自身边缘，会显示有效落点却不创建窗格；菜单分屏和 Option 复制可用，因此之前的路径验证遗漏了普通拖动。

## 行为

- 仅一个标签时，直接拖到当前窗格边缘即可保留原视图、复制出同篇分屏，预览明确显示“复制”。
- 标签栏的省略号改为可见“分屏”入口，菜单四个方向均复制当前视图，便于查看同一篇文章的不同位置。
- 多标签、跨组移动和 Option/Alt 显式复制继续使用原规则；阅读位置按视图保存，文献及 PDF 资产共用。
