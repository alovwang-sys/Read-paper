# v0.1.14 本地桌面导航修复

2026-10-23。针对研究切换像原生网页表单、名称操作不清楚的问题，调整已有导航与相邻交互；不重做研究、目录或会话模型。

## 本轮范围

- 左上研究名打开应用内弹层，支持搜索、当前项勾选、方向键／Home／End、Enter、Esc、点击外部关闭与焦点返回。经典和 Agent 工作台共用，切换仍调用原服务，保留各研究的会话、草稿与打开项。
- 同名项才显示已有目录或创建时间辅助区分；旧空名称显示“未命名研究”。全局资料库继续从左下进入，不作为禁用选项混入研究列表。
- “新建研究”按钮保持原位。Agent 仍一键开始，默认名称按“新研究”“新研究 2”递增并聚焦编辑；经典工作台保留原表单与目录流程。
- Agent 研究名使用本地编辑草稿：Enter／失焦提交非空 trim 后名称，Esc 取消，空值恢复原标题。
- 全局搜索不再重复收录白板条目。

## 两轮 Claude Code 审阅

真实 CLI 审阅记录为[首轮](review/round-1-response.json)与[第二轮](review/round-2-response.json)，对应输入保存在同目录。只提交公开源码与产品约束，没有提交真实研究资料或凭据。

采用首轮的非模态 `dialog + 搜索框 + 普通按钮` 语义、`aria-current` 标记和逐层 Esc／焦点规则。保留常驻新建按钮，弹层不再重复新建入口；研究管理“…”和底部资料库继续沿用现有位置。同名项才展示已有辅助字段，避免默认铺满路径。

第二轮指出“弹层失焦先关闭，触发器 click 又打开”的事件顺序问题，已用失败测试复现并修复。点击弹层说明导致焦点落到 body、Esc 误关窄屏抽屉也已复现并修复：鼠标点击非交互区域保留原焦点，重复点击触发器正确关闭并返回焦点；Tab、Shift+Tab 仍按正常焦点顺序退出。模型静态审阅不代替真实浏览器或桌面验证。
