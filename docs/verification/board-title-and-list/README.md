# 白板命名与列表点击验收

2026-10-24，源码增量。未重新打包或替换本机安装版。

白板工具栏显示当前名称与铅笔，白板列表的更多菜单提供重命名。名称最多 160 个字符，去掉首尾空白；空名不保存。Enter 保存，Esc／取消只关闭编辑，未提交名称按研究和白板保存，下次打开或刷新后可以继续。中文组合输入中的 Enter／Esc 不触发提交或取消。

确认保存复用共享工作区动作并等待本地保存完成；存储故障时保留输入、草稿和重试入口。标题同步到中央标签、最近打开、列表和讨论来源；白板身份、摆放、连线、共享卡片和已有对话快照保持。

白板／文稿列表沿用同一个资源列表组件，主按钮覆盖整行主体及上下留白；更多菜单保留独立按钮。保留原资源拖拽协议，拖拽结束跟随的点击不打开条目；下一次正常点击、Enter 与空格仍可打开。

## 实际验证

- `npm run check`：通过。
- `tests/e2e/board-title-and-list.spec.ts`：3/3，通过已安装的 Google Chrome，使用隔离浏览器资料、合成研究和受控服务，未操作用户论文或真实模型。
- 既有 `human-board-editing.spec.ts` 全部 4 条，加 `workspace-split.spec.ts` 的“聚焦窗格承接打开操作，论文卡片白板文稿均可分屏，卡片共享正文”：5/5。
- 新专项覆盖取消不写标题、草稿刷新、空名、组合输入守卫、保存后的多处标题同步、实体不变、刷新与研究隔离；IndexedDB 写入故障后输入和草稿保留，恢复存储后重试并刷新成功。
- 列表覆盖主体右下空白点击、Enter／空格、菜单不打开条目、列表重命名、真实鼠标拖到顶栏取消，以及合成拖拽事件的 MIME 与误触抑制。
- 1440×900、1280×800、1024×800：标题入口可见，页面无横向溢出。既有白板编辑回归另覆盖“主区白板＋右侧原文”、多窗格、研究切换和历史恢复。

当前环境没有 Playwright 配套 Chromium 缓存；本次以临时配置指定 `channel: 'chrome'`、独立端口 5185 和临时输出目录执行，未修改正式 Playwright 配置。
