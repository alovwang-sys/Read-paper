# 分层导航、人工调整与白板连线验收

2026-10-20。本轮在既有白板／原生同步工作树上完成，版本为 0.1.10；没有公开发布或修改真实研究内容。设计契约见[人工调整与 AI 协作](../../agents/human-board-control.md)。

## 已交付

- 左栏区分集合和子资源：不同类型图标、缩进、折叠、长标题省略及完整提示；白板／文稿可拖动或菜单排序。
- 研究卡片人工排序，保留拖入窗格打开的功能；筛选时显示清除筛选提示。共享实体、其他研究和白板摆放不变。
- 多选整体拖动保持相对位置与边界，一次手势只提交一条历史；方向键 1px，Shift + 方向键 10px。明确的内容编辑、原文、历史与恢复入口。
- 连线从卡片实际边缘连接，柔和曲线、方向箭头、浅底标签、选中态与宽点击热区；随正文高度和拖动预览更新，保留鼠标和键盘编辑。
- AI 改动一个旧节点的位置／分组也需确认。保留迟到结果冲突检查、纯新增自动保存、保存失败重试和版本恢复。
- 排序不再误清除关闭／收拢窗格的撤销记录；排序拖动与窗格接收层分流，保留两种操作。

## 限制

没有新增任意文件夹层级、每卡自定义图标、通用绘图引擎或新的全局撤销系统。连线尚不自动避开第三张卡片，也没有专门的树状分支排版；拥挤图仍需人工整理，或明确请求 AI 重排后确认。版本恢复只回滚布局与关系，不回滚共享正文。
