## 覆盖的用户路径

- 主区 PDF 或文稿、研究内没有白板时，从聊天直接生成；自动保存并预览，不导航主区，保留当前助手设置。点击“打开白板”才打开资源。
- 普通提问、否定、能力询问、转述、校对、已完成或未来陈述不自动创建。显式生成与按钮共用同一管线。
- 生成后普通追问携带原图节点、关系和局部引用映射作为历史数据；缩小历史会移除这部分材料，不重新读取全库，也不继承操作模式。
- 本地规则的建议仅出现一次，接受或忽略后不反复打断；接受建议保留输入区未发送草稿。
- 既有目标仅本次生效；多节点重排、移出节点或旧关系变化先预览确认。纯新增保留旧布局时可自动保存。迟到结果只属于原研究。
- 停止和无效响应不留下空板；保存失败可独立重试，不重复卡片、白板或历史。创建可撤销、恢复并刷新；恢复保存失败重试不重复记录。
- 新卡片保留待核查标记和对话/原文出处，越界引用、错误编号、原文/hash/关联变化拒绝整批写入。撤销保留已编辑或复用的卡片，清理导航、面板和选区；ZIP 和目录保留同研究卡片档案，恢复不覆盖现有正文。
- 既有版本比较、安全恢复、后续编辑冲突及独立副本路径继续通过。
