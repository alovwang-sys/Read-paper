# 卡片与绘图箭头连接修复

2026-10-21。针对用户反馈“箭头画过去没有连接”，在现有 Excalidraw 接入中补齐普通箭头绑定和移动跟随，未增加依赖或另一套白板实体。

## 已修复

原有实心卡片／论文入口本身支持原生绑定，但默认透明图形只在边框附近吸附，落在内部的箭头会保留为自由端。现在普通箭头落在矩形、椭圆或菱形内部也建立原生 `startBinding / endBinding` 和目标 `boundElements`。双向绘制均支持；已有箭头可拖动端点重新连接，不会因为浏览或刷新自动把旧自由线条连起来。

一部分斜向跨边箭头虽有绑定，原生计算出的 focus 超出图形范围，移动时仍停在原处。现在在手势完成后，只对目标已经平移、原生端点却完全未动的连接补上位移；已经正常跟随的端点不重复移动。卡片在“卡片布局”移动后返回绘图，也同步同一摆放的绑定端点。原有中间控制点保留；两端整体同移时保留整条线路。

绑定补全仅发生在本次新绘制／端点修改手势，保留另一端和原几何，尊重 Ctrl/Cmd 禁用吸附，跳过已绑定端、锁定元素、旧关系箭头和同图形自连。使用公开转换器取得原生绑定元数据，不导入绘图库私有模块、不修改图形外观。撤销／重做继续使用原生历史。

同时修正局部研究浮层的定位，避免选中卡片后遮住原生绘图工具。绘图底部不再把卡片布局关系数量显示成“0 个关系”，防止将它误认为绘图连接数量。原有卡片布局的关系计数保留。

自由箭头保存在同一个绘图资产中，移动、刷新、撤销和备份沿用现有流程。它可以连接卡片、论文入口与图形，不会自动变成支持／反驳等 `BoardEdge` 论证关系；共享卡片、资料和引用保持原实体。

## 验证

- 真实鼠标绘制卡片／论文与矩形的双向箭头，包括中心落点、斜向跨边、移动两端、刷新、删除摆放及撤销恢复。
- 一次 Undo 移除新箭头，一次 Redo 恢复；同时检查双方绑定字段，避免仅恢复外观。
- 卡片布局移动后返回绘图，端点跟随同一摆放。
- 1440×900、1280×800、1024×800：画布与右侧 AI／已渲染原文组合，输入可达，无整页横向溢出。
- 新版 Agent 工作台单独验证同一组合：唯一研究输入和发送入口保持可用，浏览来源不切换发送会话或退回经典模式；小尺寸使用原生画布缩放查看全图。
- 规则检查覆盖矩形／椭圆／菱形的内部与实际轮廓、旋转、锁定、旧箭头不自动绑定、几何与另一端保留；平移检查覆盖中间点、双方同移和原生已移动时不重复补位移。
- 原有绘图专项回归覆盖手绘、中文、共享资料入口、保存、历史、模式／研究切换和三尺寸。

11 条不同浏览器路径（连接 5、规则 2、原有绘图 4）均通过，构建及 29 文件／440 项单元检查通过。最终连接专项 5 条统一复跑耗时 37.6 秒；真实鼠标路径与规则检查分别记录，不重复计数。实际运行结果、命令和截图 hash 见 [checks.json](checks.json)。受控测试只使用本地样例和模拟连接，不调用研究模型，也不修改用户资料。

## 新建研究与目录

本轮核实并保留当前流程：Agent 工作台的“新建研究”直接创建独立研究，无须先设置目录；之后可在研究名旁的项目设置关联目录。经典工作台继续提供新建／已有目录，以及“稍后设置目录”。本轮没有改成目录必填，也未创建或变更用户研究目录。

## 边界

本次内部补吸附及跨布局端点补位移针对普通箭头；直角折线箭头继续使用原生边框吸附与路由。卡片布局的支持／反驳关系和任意绘图之间没有自动语义转换。没有自动迁移旧自由箭头、打包安装桌面应用、重跑真实模型，或进行完整混合画布迁移。
