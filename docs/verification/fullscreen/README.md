## 已实现行为

中央主窗与对照窗分别选择当前研究的论文或知识卡片，支持同篇两处、两篇论文、论文＋卡片及两张卡片。资源工作区内的已有标签可“在对照窗打开”，卡片两处编辑复用同一实体，论文独立保存页码/偏移/缩放。关闭后再打开保留最近对照对象和布局；研究页面、右侧 AI 与来源面板沿用原宿主。旧版 `readerSplits` 在加载时迁入 `mainSplit`，阅读位置键不变。

macOS 原生全屏的顶部窗口按钮由系统管理，不能把用户反馈直接归因为 CSS 覆盖。本轮确认全屏后应用内没有可靠退出入口。原 CDP 自动化没有进入 Electron 原生快捷键链路，不能据此判定系统菜单或物理按键故障；本轮以官方 `webContents.sendInputEvent` 验证生产快捷键处理。新增全屏常显“退出全屏”，仅可信主窗口可查询/退出；监听真实 enter/leave 事件，刷新可恢复状态。窗口级 before-input-event 补 ⌃⌘F／F11，消费菜单重复处理，长按不反复切换，不抢 Esc、IME 或其他组合键。保留原生框架、关闭前保存与系统设置。

快速滚动后立即分屏曾复现真实时序缺陷：当前可见第 2 页，180ms 防抖尚未写入，布局缩小即按旧持久位置恢复至第 1 页。真实包探针记录了 ResizeObserver 和 scrollTo 时序；修正区分布局恢复与主动导航，跨页及时保存，页内偏移仍防抖，避免布局清掉最新待写位置。新文献的几何布局恢复完成前，不解释旧滚动事件。原桌面用例保留完整页码和持久化断言，修复后独立连续 3 次通过；[修复前时序证据](reader-position-race.json)。

初始空工作区也统一执行现有 schema 规范化，保证首次导出与恢复的默认会话字段一致；此前依赖是否曾挂载 AI 触发隐式补全。没有通过放宽备份内容比较来回避差异。无全文资料可在对照窗查看摘要和来源，但不创建虚假的 PDF 阅读位置；迁移清理旧的无全文界面位置，证据页码校验仍严格，完整备份可往返。
