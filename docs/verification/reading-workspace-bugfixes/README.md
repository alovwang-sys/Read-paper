日期：2026-10-19。基线：本地 `main` 的 `ef5f104`；修复分支：`codex/fix-reading-workspace`，使用独立工作树，原工作区未提交修改保留。

## 修复行为

- 文献的“…”菜单增加“移出本研究”和“从资料库删除”，资料详情也提供入口。操作前确认，引用保护失败后持续显示具体原因。移出清理该研究的打开项、预览、未发送材料和收录备注/发现记录，保留全局文献、独立摘录与其他研究。卡片、文稿、白板、已发送材料和原文旁问答仍依赖来源时阻止移出；资料库中的独立条目可删除。删除不会修改其他研究的空工作区。
- AI 面板取消 420px 的最小宽度，与其他面板均可缩至 320px；常用三种尺寸中央至少保留 560px。两侧调宽相应约束，宽度偏好随刷新恢复，1024px 的导航继续使用抽屉。材料与历史范围默认折叠，摘要显示数量，展开后可核对和移除；标题区与输入区减少占用。关闭/重新打开右侧和刷新均保留未发送问题。
- AI 来源原先按空行提取推荐段落，连续列表会将整段回答保存到各文献。现在只取对应链接所在条目的简短说明，无法可靠区分时使用标题；预览与详情也将旧版整段快照显示为局部说明。原问题与完整回答留在“回看原问答”。
- Codex、Claude Code、OpenCode 读取原生历史时，先剥离 Read-paper 自有材料包装，再执行长度限制。长材料不再挤掉位于末尾的真实问题，requestId 保留用于去重。旧版污染造成的重复显示在刷新原生记录后移出会话列表，原始问答和来源存档保留。
