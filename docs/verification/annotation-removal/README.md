# 阅读标记移除验收

日期：2026-10-19。修复分支：`codex/fix-reading-workspace`。本次承接资料与 AI 修复，在同一独立工作树完成。

## 确认与修复

原有“取消摘录”在卡片引用摘录后会被禁用，已在页面复现并保存[基线截图](baseline-card-disabled.png)。服务层还会阻止删除 AI 上下文或请求引用的摘录；这一项通过原实现确认。

- 点击文章中的文字高亮或区域标记，可使用“移除标记”；右侧摘录列表也提供同一操作。移除仅隐藏阅读标记，保留摘录、区域资产、卡片、AI 问答和引用。
- 在摘录列表点击“恢复标记”，或再次摘录相同内容，可恢复标记并复用原摘录 ID。移除状态随保存、刷新与备份恢复保留。
- 移除时清除当前来源定位的临时高亮，原文旁问答继续保留。之后主动点击引用仍可临时定位原文，不会恢复持久标记，也不会新开重复标签。
- 相同文字在多个研究中存在时，优先使用实际点击的摘录 ID；区域标记在旋转后仍可识别。移除不会改变其他摘录或研究。
- 新建摘录的“撤销”仍保留引用保护，并补充原文旁问答和文稿卡片引用检查，避免删除仍被使用的来源。
