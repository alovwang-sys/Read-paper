## 双客户端连接可行性

[探针](shared-daemon-probe.mjs)使用本机 Codex CLI 0.162.1、临时隔离 CODEX_HOME 和本地模拟 Responses 提供方，验证两个 WebSocket 客户端连接同一 App Server：第二端加入正在运行的同一线程，观察端断开后重新加入，收到同一回合的增量和完成事件；本地提供方只收到 1 次调用，真实模型调用为 0。独立 stdio App Server 可读落盘历史，但不能取得另一个服务持有的活跃 writer。结果见[机器记录](shared-daemon-probe.json)，探针自有进程与临时目录已清理。

[官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)区分 thread/read、加载订阅与实时传输；WebSocket 传输仍标为实验性。当前机器没有可用的默认 daemon socket，Papertrail 与独立 Codex 桌面未接到同一个服务端点。本探针证明连接方式可行，不证明已完成独立桌面的双向实时接管。未删除 writer 锁，也未抢占其他客户端。
