# 0.1.17 独立打包验收

本轮启动的是仓库 `out/Papertrail-darwin-arm64/Papertrail.app`，未启动或操作 `/Applications` 中的真实用户 App。包内版本为 **0.1.17**，标识为 `io.github.alovwang-sys.papertrail`。每项测试使用独立临时 HOME、userData、模型配置目录和受控响应，不读取真实论文、会话或模型凭据。

## 实际结果

`tests/desktop/continuous-workspace.spec.ts` 的既有两项测试 **2/2 通过**；测试命令退出码 **0**，Playwright 报告耗时 **13.0 秒**（含外层准备共 13.55 秒）。

- PDF 旁发送问题后直接显示回答；同一会话在侧边、浮窗、主区之间切换；草稿不丢失、输入框只有一份。1440×900、1280×800、1024×800 下输入框完整可见、无页面横向溢出。
- 在真实 PDF 字形上选择原文，翻译、生成并保存摘要卡片；原文操作记录、卡片引用和未发送主会话草稿均在正常退出后重启恢复。
- 两项分别执行退出、重启和最终退出，共四次正常退出均由测试断言进程退出码为 **0**。每次启动断言 `papertrail://app/`、隔离 userData 路径、版本与当前 package 一致、渲染器未暴露 Node require。
- 打包测试产生的临时资料目录全部清理；完成后没有本轮 `out` 包进程残留。原有 6 张截图先备份，采集本轮证据后全部原字节恢复，SHA-256 均一致；临时备份随后清理。

## 证据

- `desktop-run.log`：实际命令、两项逐项通过及耗时。
- `desktop-acceptance-results.json`：包版本/标识、命令退出码、旧图新旧 SHA-256、隔离目录和进程清理结果。
