# 研究目录与对话记录交互设计

2026-10-17，第一版交互实现与后续设计边界。依据[产品需求](project-sessions-requirements.md)，以[可点击原型](project-sessions-prototype.html)评审主要路径。原型仍只用于示例评审；生产工作台已经接入本机目录服务和原生会话列表/读取通路。实际能力与三尺寸实现截图见[验收记录](../verification/project-sessions/README.md)，不能用原型模拟状态证明真实客户端互通。

用户的日常动作是继续阅读、找到上次讨论和带着材料追问。目录、原生身份和同步机制为这些动作服务。界面默认展示内容和下一步，具体路径、会话 ID、配置及兼容性集中到详情。

## 信息架构与入口

继续使用现有三栏及单一右侧宿主。左侧研究决定项目归属，中央负责论文和资源标签，右侧在对话、对话记录、草稿及来源之间切换。不增加第四栏或第二套全局打开项。

| 位置 | 默认可见内容 | 用户动作 |
| --- | --- | --- |
| 左侧研究项目 | 一行项目名称下拉与“…”设置入口 | 名称切换研究；“…”查看项目位置、连接状态或重新连接 |
| 中央 | 统一资源标签、论文工具条和最大阅读区 | 阅读、切标签、点引用定位、保留返回位置 |
| AI 标题栏 | 当前对话标题、“对话记录”和“新对话” | 找记录或新建；标题截断时可查看完整名称 |
| 对话记录 | 搜索；全部/Codex/OpenCode/Claude Code 筛选；当前研究的会话列表 | 点击整行打开，刷新，返回当前对话 |
| 输入区 | 本轮材料摘要、问题输入、唯一助手切换入口、发送 | 查看材料、选择助手、提问；模型/模式/技能收纳在相邻工具行 |
| 目录设置与对话范围 | 完整目录、来源与原有上下文说明、当前继续限制 | 需要核对时展开；原生应用交接按钮待实机验证后提供 |

常用动作显示文字，图标只作辅助。原生会话 ID、多个配置下拉、所有连接状态和备份按钮不同时堆在聊天工具条。

## 主要路径

### 首次关联研究目录

2026-10-17 已接入[新版创建流程](research-directory-design.md)：默认“创建新目录”，显示研究名称、研究问题、父位置与完整路径，也可切到“使用已有目录”。确认前预览，失败保留填写内容；同工作区归属可确认时提供冲突跳转。桌面使用原生目录选择器，浏览器沿用本机服务目录选择器。[原型](research-directory-prototype.html)保留为设计基线。

选择“稍后设置”的研究可先命名、填写问题和整理资料。第一次使用原生助手时，输入区就近提示“为这个研究选择目录”，主按钮“选择研究目录”，保留已输入的问题和材料；模型直连和本地阅读不受影响。

项目设置使用一个简短对话框，说明项目名称采用所在文件夹名称，原生对话归属此目录。第一版浏览已有本机目录，支持输入绝对路径快速定位。选中后预览“项目将命名为「文件夹名」”和真实路径；点击唯一主操作“使用这个目录”才检查写入条件、创建项目清单、保存关联并同步名称。新子目录在新建研究表单中创建。“取消”关闭并返回触发处，不改名、不清空输入，也不创建半完成项目。

重复目录显示归属冲突原因；只有同一工作区可确认归属时提供“打开已有研究”。不可访问显示具体原因并保留路径。目录已包含运行时可发现的会话时，确认绑定后在本研究历史中发现，不额外问用户逐条导入；Claude Code 只读取适配器已知项目历史，Desktop 独立列表与交接尚未实机验收。绑定只建立关联；目录迁移和删除不在此入口提供。

### 日常继续讨论

打开研究恢复上次助手、对话、原文页码、未发送输入和草稿。项目名称与目录名保持一致，已有项目成功检查连接后同步标题；研究 ID、核心问题和内容不变。完整路径与连接状态只在项目设置中展示，无需重新选目录、逐次确认会话或点同步。

聊天顶部“新对话”沿用当前助手，新对话不带旧对话历史；本轮材料按现有显式添加规则处理。旧输入与草稿留在旧会话。新标题在第一轮后产生，用户可改名；同名会话靠来源和时间区分。

切换助手时恢复该助手最近会话，发送按钮随实际就绪状态更新。不弹确认框，不把当前问题自动提交给另一助手。无历史进入新对话。两种助手中的未发送输入各自保存。

### 找原生客户端中的讨论

“对话记录”在右侧替换聊天正文，中央 PDF 保持原样。列表初次按最近更新排序，当前打开的会话有文字标记。每行只保留标题、助手、消息预览、时间；“来自原生客户端”“运行中”仅在相关记录上显示。

搜索作用于已发现的当前研究记录；字段范围在占位文案或帮助中说明，不能把只搜标题称为全文搜索。筛选不改变当前助手、不发送请求；点击会话才切换到它的助手并打开记录，光标回输入区时不覆盖已有草稿。

刷新更新可获得的标题、时间和状态；只在打开记录后读取正文，已有本地正文可参与搜索。首版不提供跨客户端未读计数，不把阅读中的对话强行切走。打开已选会话加载增量；用户位于消息底部才自动滚动，向上查阅时出现“有新消息”按钮。

### 从原生客户端接回会话

首次打开外部会话，先展示已读取的历史和一条“包含原有对话上下文”的说明，详情可查有效范围；不是每轮弹窗。状态确认可续接后，底部恢复发送；未认证或版本不支持时仍可读历史，并提供对应恢复动作。

第一版尚未提供“在原生应用继续”或“复制定位信息”动作。后续须先实测对应客户端的定位或交接协议，再提供次级入口；不以复制成功冒充原生应用已打开，不通过终端视图伪装桌面互通。

外部正在生成时，输入可编辑，发送暂时不可用；明确显示“正在原生应用中运行，完成后可在这里继续”。可手动刷新，已阻止续接的会话在窗口可见时定期只读刷新；目前没有未验证的交接按钮。此时不提供停止他人任务或隐式新建副本的快捷动作。

Codex 的 unknown 状态先尝试原子续接。若尚未发送当前问题就收到 writer 占用错误，自动保留历史并在独立副本继续一次，回答旁常显“已恢复对话”，说明原会话由后台保留、原记录不受影响，不要求用户寻找释放入口。当前研究、逻辑对话和旧消息来源保持，原生 ID/ref 更新为副本；累计材料保留，下一轮和刷新后继续使用副本。失败时明确“本次问题未发送”，保留原关联与输入；新写的草稿优先，不覆盖。外部 OpenCode/Claude Code unknown 保持只读；已知生成中或停止未确认仍禁发，不能经刷新自动解除。

### 对照来源

点击回答中的有效引用，中央复用已有论文标签并定位对应页和摘录；右侧保持消息、输入和滚动。点击网页链接打开浏览器，按钮或链接文案说明目的地。未关联外部文件可查看名称和摘录，再显式关联研究资料，不猜测它属于某篇论文。

原生消息整理成卡片时进入既有独立草稿编辑流程，显示对话来源与可验证的论文来源。用户确认后才写入卡片，返回对话恢复原位置。

### 保存和找回

左栏底部显示目录文件保存状态，可点击重试；项目设置说明 `Papertrail/` 中的实际资料文件、应用恢复副本、`.read-paper` 请求归档和厂商原生记录的职责。编辑后自动更新，本机聊天先等待目录保存；保存失败保留输入，不发模型。外改文件保留并暂停覆盖。会话文件保存可读历史、原生 ID 和 Codex 续接命令，不能把 Markdown 当作原生日志。“存储与设置”继续提供完整工作区 ZIP 备份；目录独立恢复、外部编辑回写和原生索引跨设备恢复尚未实现。

旧临时目录下的会话保留“旧版阅读对话”标签并可读，关联研究不会自动改变其原生目录。需要把旧内容带入新项目时，点击“在研究目录开始新对话”，建立新的干净会话，旧记录和输入仍保留，不标成同一会话搬迁成功。

## 页面状态与文案

| 状态 | 展示 | 恢复动作 |
| --- | --- | --- |
| 正常 | 对话与材料为主；原生来源说明及“刷新记录” | 继续输入 |
| 未绑定目录 | 输入保留；“为这个研究选择目录” | 选择研究目录 |
| 首次加载历史 | “正在读取对话记录”，已有软件记录仍可读 | 保留返回入口 |
| 刷新历史 | 原列表继续可读，刷新按钮短暂禁用 | 完成后原位更新 |
| 无记录 | “这个研究还没有对话” | 用当前助手新建 |
| 搜索无结果 | “没有找到匹配的对话” | 清除搜索，保留筛选 |
| 原生端忙碌 | 已读历史和可编辑输入；发送禁用并说明原因 | 自动更新、刷新；不提供停止外部任务 |
| 同步失败 | 上次记录继续可读；“暂时无法更新，显示上次记录” | 重试读取；不重发问题 |
| 目录失联 | 路径保留；历史可读、输入可编辑 | 重新连接目录 |
| 原生记录缺失 | 原有来源快照可读；就近说明读取原因 | 重新读取，或明确新建对话；不自动复制历史 |
| 续接状态无法确认 | 显示具体限制与已读内容 | 只读查看或明确新建；Codex 单独使用原生 writer 锁 |

“同步失败”的重试只读历史；“请求失败”的重试可能生成新请求，两者使用不同按钮与说明。归档或移出列表默认只影响本软件显示，不删除原生会话；原生删除若以后提供，必须独立明确其影响。

## 点击与视觉规范

沿用项目浅色灰绿背景、白色论文和深绿主操作。标题突出研究内容，来源与运行状态采用低强调文字；错误色只用于当前需要处理的问题。使用一条细分隔组织内容，避免卡片套卡片、多层阴影、整屏仪表盘和与阅读无关的指标。

常用按钮至少 36×36px，主要操作高度 40px；列表整行可点，行内次级菜单有独立目标，不重叠。长标题最多两行或单行截断并提供完整可访问名称；完整路径在详情可选中复制。一个局部任务只有一个主要按钮。

聊天正文和输入至少 14px，常用动作与侧栏约 13px，来源、状态和材料说明至少 12px；辅助文字保持可读对比，不用浅灰小字承载必要操作。论文自身字号由阅读缩放控制，不能为容纳更多控件而缩小整页界面。

键盘可到达全部入口；会话列表的标题和状态可朗读。弹窗打开后焦点进入，Tab 不逃出，Escape 关闭并返回触发按钮；保存失败保留对话框输入。颜色之外同时提供文字状态。加载不更改行高造成目标跳动；返回时保留列表搜索、筛选和滚动。

| 尺寸 | 第一版已检查布局 |
| --- | --- |
| 1440×900 | 左栏沿用现有框架，右栏可调至 440px；中央论文是最大单区 |
| 1280×800 | 右栏 440px 时中央约 620px；对话记录与论文并列，无整页横向溢出 |
| 1024×800 | 沿用框架的折叠导航/菜单，右栏 440px、中央约 584px，仍并排 |
| 小于 1024px | 沿用现有覆盖抽屉；先保留一个清晰任务区，关闭 AI 回论文 |

中央正文和右侧消息独立滚动，输入区固定在右栏底部；材料、目录提示及范围设置独立滚动，异常说明增多时也不把输入框藏到下方。历史和目录设置不创建新的主区资源标签。

## 评审与可用性验收

从页面已有入口计，打开对话记录 1 次点击；打开一段可见历史再 1 次点击。已绑定项目发送问题无需额外项目选择或常规确认。从已展开正文点击有效引用 1 次即可定位中央来源。

观察用户完成五件事：绑定目录后返回原问题；找到来自原生客户端的会话；切换助手后找回未发送输入；识别外部忙碌并等待；核对回答引用而不丢失对话。记录完成率、错误点击、是否需要解释按钮含义；不把原型走通等同于真实易用性已证实。

第一版确定性测试覆盖目录取消/确认、身份去重、筛选、只读打开、忙碌禁发、输入保留、外部增量、备份兼容和中央引用；目录弹窗的 Escape 返回不会连带关闭右栏。真实模型往返、各原生桌面客户端定位、认证受限连接及项目目录独立恢复仍单列待验收；测试数据和原型均不充当真实互通证据。
