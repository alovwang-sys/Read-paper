# 研究项目会话互通实施计划

2026-10-17，第一版已实施，按能力继续验收。依据[产品需求](project-sessions-requirements.md)和[交互设计](project-sessions-ux.md)，复用现有 React 工作台、本地 Node 服务和共享实体；没有新增通用插件平台、多 Agent 编排或 npm 依赖。原型保留为设计基线，实际进度以[验收记录](../verification/project-sessions/README.md)为准。

## 第一版采用的默认项

| 决策 | 实际行为 | 边界 |
| --- | --- | --- |
| 目录绑定 | 首次原生聊天前选择已有本机目录，确认后写项目清单 | 不阻塞人工阅读或模型直连，不自动迁移论文/卡片 |
| 原生历史 | 沿用厂商原生存储；项目保存请求、材料与可读历史归档 | `.read-paper` 不是完整数据库备份，认证不归档 |
| 发现范围 | canonical 根目录精确匹配；原生 ID 与 Agent 联合归并 | 子目录/worktree 不默认并入父项目，读取时再次校验归属 |
| 继续与占用 | 原生 ID 显式续接，已知 busy 一律拒绝 | Codex unknown 可凭排他 writer 锁尝试；外部 OpenCode/Claude unknown 只读 |
| 自建会话与停止 | 保留本软件已映射会话的续接，停止只针对自己启动的请求 | 停止未确认持久只读，不抢占外部任务、不自动另开或重发 |
| 旧临时会话 | 保留只读历史与未发送输入，明确在研究目录新建 | 不暗中改变原生 cwd 或宣称旧记录已迁移 |

## 阶段进度与下一步

| 阶段 | 第一版已完成 | 尚待放行的证据或功能 |
| --- | --- | --- |
| PS0 实机兼容探针 | Codex 真实目录创建/发现/读历史/同 ID resume 与跨进程 writer 锁；OpenCode 真实创建/发现/用户消息读取；Claude 未认证边界已记录 | 三种原生桌面应用列表定位；真实回答及两端往返。探针不等于完整互通 |
| PS1 项目绑定与保全 | 目录浏览、路径预览、确认绑定、项目标识、重复绑定保护、原目录重连；旧数据不改归属 | 新子目录的界面创建入口、冲突时直接切已有研究；真实用户资料长期恢复 |
| PS2 Codex 路径 | 项目 cwd 与材料快照分离；list/read、稳定去重、显式同 ID 续接与 writer 锁拒绝；原有技能/模型/审批保留 | P02 完整客户端往返。生产适配器固定短请求约 85 秒没有可见回答后主动停止，本轮不标真实问答通过 |
| PS3 OpenCode/Claude Code | 同一公共 UI 与项目合同；适配器发现/读取；外部未知占用只读，已知忙碌禁发，自建会话保留续接 | OpenCode 两次限时请求未完成真实回答；Claude 本机未认证，模型请求与 Desktop 独立列表未验收 |
| PS4 归档与恢复 | `.read-paper/project.json`、请求/材料快照、已读原生历史可读归档；JSON 原子替换、失败说明；卡片来源独立保留 | P08 完整 PDF/图片/业务数据备份恢复；registry 仍在 `AI_AGENT_STATE_DIR`，项目目录单独复制不足以恢复原生映射 |
| PS5 集成验收 | 目录取消/绑定、去重、部分连接失败、只读打开、忙碌与输入保留、引用中央定位；三尺寸实现截图 | 三种真实客户端往返与用户可用性观察；完整备份恢复不能由模拟测试代替 |

后续先补真实模型回复与原生应用定位证据，再开放未经证明的交接入口。认证不足或某次请求超时只记录当次事实，不据此判定供应商整体不可用；也不通过重复付费尝试、移动用户原生记录或修改数据库规避边界。

## 已落地的共享合同

| 责任 | 当前边界 |
| --- | --- |
| 研究绑定 | `Research.directory` 保存 binding ID、稳定 project ID 与规范路径；本机服务校验目录与 manifest，阻止直接改绑 |
| 原生身份 | `nativeSessionRef` 是服务端不透明引用，原生 ID 与项目/Agent 校验后可续接；跨浏览器身份映射保存在 registry |
| 请求材料 | 原生 cwd 使用研究根目录，每轮材料生成独立不可变文件，保留证据 ID、文档 hash 和 0 起始页索引 |
| 外部消息 | 原生消息 ID 去重；只读映射为显示缓存；相同身份刷新可更新缓存，软件原始回答仍不可改写；卡片已有来源快照独立 |
| 继续与取消 | list/read 不运行模型；run 校验 binding/ref 和占用；不停止用户 daemon 或其他客户端任务；未确认停止持久保留限制 |
| 持久化 | 论文、图片与知识实体仍以 IndexedDB 为业务来源；项目清单、可读归档、厂商原生记录及服务索引分别负责不同职责 |
| 来源 | 外部原文不自动转换为论文证据，无法映射时保持可读并说明材料未关联；不能把零本轮材料解释为零原有上下文 |

服务接口集中在既有 `src/services/agents.ts` 与本地 `/api/ai/agents/projects/{browse,preview,bind,status,list,read}`；既有 `openResource / setSelection / addContext`、主区标签和单一右栏继续复用。

## 验证与分工

集成负责人维护 domain/services/data/shell、项目服务、依赖和迁移；运行时执行者维护各 Agent 适配器及协议测试；UI 在既有 `AIPanel / ConversationHistory` 接入目录与记录。不创建第二套聊天状态，所有执行者保留他人改动。

确定性测试验证身份映射、输入保全、去重、错误恢复、引用完整性和隔离；实机探针验证真实协议与运行占用。已通过 `npm run check`、`npm test`、`npm run test:server`、`npm run build` 与全部 `npm run test:e2e`，结果由[验收记录](../verification/project-sessions/README.md)统一维护，不复用原型自检数字作为生产测试结果。

三尺寸实现覆盖 1440×900、1280×800、1024×800，截图明确使用模拟原生响应。原型的 10 组自检保留为独立设计评审记录，真实模型冒烟、原生客户端验收和 P08 备份恢复分别记录。
