# 人工调整与 AI 白板协作

2026-10-20 用户确认并要求实现。状态：本轮交互已实现，macOS arm64 本机已安装 0.1.10；实际验证与截图见[验收记录](../verification/human-board-control/README.md)。未公开发布，也不代表 issue #6 的全部知识库版本管理已经完成。

## 产品原则

AI 生成的是可编辑初稿。用户决定卡片的内容、位置、先后关系和分组，不需要再次请求 AI 才能调整结果。人工与 AI 创建的卡片使用相同的编辑能力，来源继续保留。

沿用用户选择的“分层导航”：集合入口与具体资源区分，同类资源保持一致图标。左侧导航排列、白板空间布局与概念间的论证关系分别处理，不能通过一次拖动悄悄改变另外两者。

## 操作约定

| 场景 | 预期行为 |
| --- | --- |
| 白板内微调卡片 | 显示可发现的拖动入口；允许手动移动、多选移动、调整分组和编辑关系。移动只改变本白板摆放，不改共享卡片正文或其他白板 |
| 修改 AI 生成卡片 | 提供明确的“编辑内容”入口，允许改标题、正文；继续保留原始对话和来源。共享正文影响其他使用处时沿用已有共享提示 |
| 调整左侧条目顺序 | 同一研究、同一类型下的白板与文稿可拖动排序，并提供“上移 / 下移”等无需拖动的等效入口。首次沿用当前顺序，新建项追加，不自动重排已有项 |
| 调整卡片列表顺序 | 研究内卡片列表允许手动排序，按研究保存；它不改变同一卡片在白板上的位置，也不通过创建时间强制恢复原序 |
| AI 首次生成 | 用户明确要求后创建可编辑初稿，聊天显示已生成和打开入口；保留当前阅读位置，不把图作为不可编辑图片 |
| AI 再整理已有白板 | 以当前保存状态为输入；默认保留已有位置。涉及移动或重新分组已有卡片时，先展示变化再由用户应用。任一旧节点变化均需确认 |
| 生成期间用户继续修改 | 迟到结果不得覆盖新修改；保留建议并说明冲突，用户可按最新状态重新整理 |
| 撤销和恢复 | 人工调整和 AI 应用都能追溯与恢复；移出白板保留卡片实体；不通过恢复布局回滚共享正文 |

白板是自由画布，没有天然的“第几张”。用户调整空间位置表示自己的阅读安排；连线方向及文字才表达依赖、先后或论证关系。拖动节点不会自动改写连线或重新运行 AI 排版。

## 本轮实现

- 集合入口使用白板网格／文稿本图标，子资源保持同类图标、缩进与轻量层级线；折叠按研究保存。导航及研究卡片列表均可拖动调序，也可通过手柄菜单上移／下移。筛选卡片时先清除筛选再调序。
- Shift / Ctrl / ⌘ 多选后拖动任一选中卡片，整组保持相对位置；拖动中只预览，松开后一次提交和一条历史。方向键每次 1px，Shift + 方向键每次 10px。
- 卡片明确提供“编辑内容”和“原文”入口；工具栏显示“历史与恢复”。编辑共享正文沿用右侧编辑器，恢复布局不回滚正文。
- 曲线按真实卡片边缘、高度和拖动预览更新，支持横向、纵向及反向关系；箭头保留方向，标签有浅底，选中关系高亮。狭窄间距会截短或隐藏标签，完整说明保留在悬停、可访问名称及关系编辑器中；无文字连线通过热区选中后添加说明。
- 顺序在研究实体的可选 `boardOrder` / `draftOrder` 与已有 `cardIds` 中保存；折叠使用会话可选 `collapsedNav`，兼容旧 schema 3。新资源追加；旧顺序里的已移除 ID 不会复活资源。迁移、备份和目录归档验证归属与格式。
- AI 对已有位置、分组或关系的改动均先预览。仅新增且保留旧布局和关系时可自动保存；迟到的过期方案仍拒绝覆盖。

## 连线与后续图形设计边界

当前自由画布保留研究者的摆放；曲线美化不改变关系含义。分类图适合明确父子分支，流程图适合有方向的层级，证据图允许交叉关联。后续若增加专门布局，应先显式区分关系类型和图形用途，再由用户预览并应用；不能因为节点相邻就推断为父子关系，或用随机颜色伪装语义。

第三张卡片避障、自动树状布局、分支折叠、主次关系线型尚未实现。现有 flow 布局仍使用确定性的拓扑分层；环路不会强行解释为树。拥挤图可先人工多选调整，或明确请求 Agent 整理后确认变化。

## 验收要求与证据

- 用户无需模型调用即可调整 AI 生成卡片的内容与布局；拖动、键盘/菜单操作结果一致。
- 切换研究、切换标签、刷新或重启后保留人工顺序和布局；不同研究互不影响。
- 手动排序不破坏当前选中项、打开标签、输入草稿或引用；新生成白板不重排已有条目。
- 人工改过的位置不会被普通追问、迟到响应或未经确认的重新整理覆盖。
- 卡片列表排序、白板摆放、连线含义分别持久化；同一卡片的正文仍共享。
- 1440×900、1280×800 与 1024px 抽屉内都能看到父子层级、拖动落点与非拖动替代入口。

本轮不增加任意层级文件夹、每张卡片自定义图标或通用布局引擎。
