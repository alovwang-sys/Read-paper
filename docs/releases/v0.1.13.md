# Papertrail v0.1.13

本版将 [PR #30](https://github.com/alovwang-sys/Read-paper/pull/30) 的修复编为独立版本，避免与旧 v0.1.12 同号。公开状态、固定源提交、发行检查和安装包下载以 [GitHub Release](https://github.com/alovwang-sys/Read-paper/releases/tag/v0.1.13) 为准；本文随版本准备提交，不代表发行工作流已经完成。

## 变化

- 修复默认 Agent 工作台额外的长问题限制、发送后输入残留、完整回答难找和文献无法收录。执行细节折叠，成果正文直接显示，支持定位最新回复。
- Codex 研究工具可通过 OpenAlex 检索文献，在对话中预览、收录和继续追问；保留候选出处、历史和摘要。请求超限时明确提示并保留草稿，不静默裁剪历史。
- 聊天支持上传、粘贴和拖入 PNG、JPEG、WebP 原图，最多四张、每张 8 MiB，包含绘图选区；本轮附件与会话、冻结重试、备份及研究目录保持一致。修复图片能力探测超时误判。
- 复用系统听写入口，识别文字留在草稿；保留 Excalidraw 绘图、卡片连接和框选问 Agent，以及经典工作台与已有资料。

## 验证口径

PR #30 合入时通过 744 项单元、355 项服务端、27 项桌面协议、15 项发行保护、273 项浏览器测试，以及 macOS arm64、macOS Intel x64、Windows x64 各 19 项打包应用测试。Intel Mac 恢复浮窗用例首轮超时，同一提交定向复验通过；本机原用例及四次受控慢加载检查通过，首次间歇超时根因未确认。

本版只调整包版本和文档，发行工作流仍须对 v0.1.13 固定源重新运行全部检查并校验八份附件。此次发行不重复调用真实付费模型；此前真实 Codex 检索和双图识别验证，以及模拟流程、截图和容量边界分别见 [对话回归](../verification/agent-regressions/README.md)、[图片与听写](../verification/chat-inputs/README.md)。

## 下载与升级

- Apple 芯片 Mac：`Papertrail-0.1.13-macos-arm64.dmg`。
- Intel Mac：`Papertrail-0.1.13-macos-x64.dmg`。
- Windows x64：`Papertrail-0.1.13-windows-x64-setup.exe`。
- 同时提供两个 Mac ZIP、Windows `.nupkg`、`RELEASES` 及 `SHA256SUMS`；后两项 Windows 元数据保留原名。

没有自动更新。升级前可在“设置 → 工作区备份与恢复”导出完整 ZIP，退出应用后安装。完整备份包含原 PDF 和图片，不含 API key，总内容上限 256 MiB、单项资产 64 MiB；恢复为整库替换。Markdown 导出不是完整备份，浏览器与桌面资料不会自动同步。

## 当前边界

- 保持未签名 Pre-release：尚未配置 macOS Developer ID、Apple 公证或 Windows 发行者签名，安装可能出现系统信任提示。CI 启动的是打包应用，不能替代 DMG / Setup 人工安装。
- Windows / Intel 安装器、干净环境与跨版本升级人工验收未完成。此前本机安装的是同功能的 v0.1.12 修复构建，不能算作 v0.1.13 安装包验收。
- 新增图片研究工具目前仅接 Codex，所选模型须声明图片能力；Claude Code、OpenCode 保留原有连接能力。旧图片不会在后续问题中自动重发。
- 语音是系统听写入口，没有内置录音上传或转写；本轮未验真实语音识别。
- 上下文仍有容量保护；不承诺无限上下文、原生 Skills / Plan 继承或完整原生客户端体验。没有自动获取所有论文全文，也不自动收录候选。
