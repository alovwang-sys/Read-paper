# Papertrail v0.1.7 — AI 上下文与阅读小窗修复

本版修复 AI 续聊的上下文限制、发送后的草稿回填，以及原文旁小窗的位置和尺寸调整。

- Codex 聊天使用原生会话管理历史，安全续接时不重复注入已发送的历史；应用按本轮实际发送内容校验容量，继续校验材料来源、引用及研究范围。
- AI 已返回部分内容后遇到错误，原问题留在消息记录并提供重试，避免再次出现在输入框；尚未得到回答的失败仍保留可恢复输入。
- 原文旁 AI 小窗可拖动标题栏移动、拖动右下角调整尺寸，也可聚焦相应控件后用方向键操作，按 Shift 加速。窗口缩小时自动约束在可用视口内。

验证结果与截图见 [本版验收](../verification/ai-fixes-017/README.md)。普通回归使用确定性模型/助手响应，不代表真实模型长对话压缩已通过。

## 安装与升级

- macOS Apple 芯片：`Papertrail-0.1.7-macos-arm64.dmg`
- macOS Intel：`Papertrail-0.1.7-macos-x64.dmg`
- Windows x64：`Papertrail-0.1.7-windows-x64-setup.exe`

正常升级沿用已有应用资料。建议升级前从设置导出完整工作区 ZIP；`SHA256SUMS` 用于核对附件完整性。

本版继续作为未签名技术预览发布，未配置 macOS 公证及 Windows 发行者签名，没有自动更新。跨平台构建和打包应用测试以本版发行流水线为准；Windows/Intel 安装器人工安装与升级验收未完成。
