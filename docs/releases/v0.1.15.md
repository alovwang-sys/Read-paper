# v0.1.15 本机体验版

本轮将此前独立讨论的连续工作区接入真实应用，不再使用示例原型承载功能。版本号、应用名、bundle ID、固定本地 origin 和用户数据目录保持既有身份，升级只替换程序。

## 变化

- 左侧会话列表缩为单行；回答显示在当前聊天，同一会话可切完整、侧边和浮窗。普通研究助手切换保留话题、草稿和旧成果；未支持的待发图片明确保留并禁发。
- 保留真实 PDF、浏览器式标签拖动分屏、白板 Excalidraw、文献收录与现有连接。卡片和摘录从固定顶栏进入独立浮窗，可查找、编辑和回到原文。
- 文字和区域选区就地提问、翻译、生成可编辑摘要卡片；操作与失败记录能从原文找回。不同位置独立会话，翻译／摘要任务不混进问题历史。
- 首次局部提问共用本篇文章简要，按文档 hash 与提取版本缓存，每轮冻结快照。只读取本篇可提取文字，最多24页、50,000字符、每页6,000字符；展示覆盖与截断，作为背景而非引文。停止／失败／仅按选区重试与目录变更保护保留。

## 验证与安装

实际结果、受控接口边界、三尺寸截图及安装状态见[实施验收](../verification/continuous-workspace/README.md)。本轮仅构建 macOS arm64 本机体验包，没有创建或发布 GitHub Release，也未推进远端合并。

本机已安装并打开 `/Applications/Papertrail.app` 的0.1.15，原软件已移入废纸篓并另有完整备份。用户数据及加密设置保留的实际核验见[安装记录](../verification/continuous-workspace/local-install.md)。

## 已知边界

真实供应商对新简要提示的回答质量未在本轮重测；浏览器和打包交互使用受控接口及真实自制 PDF。简要不是完整全文记忆，没有OCR；失败需重试或仅问选区。Claude Code／OpenCode／模型直连保留原能力，未接 Codex 新研究工具；语音沿用系统听写，没有应用内录音转写。语义相近会话推荐暂未实现，当前提供搜索、选择和新建。

未配置 Developer ID／macOS 公证、Windows 签名或自动更新。只验证本机 Apple 芯片构建；其他平台未本轮构建验收。
