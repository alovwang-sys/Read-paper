# Papertrail v0.1.2 — 研究知识链路与本地目录

这是未签名的技术预览，适合自愿试用。macOS 提供 Apple 芯片 arm64 与 Intel x64 安装包，Windows 提供 x64 安装器；下载时按架构选择。

## 本轮变化

- 左栏按当前研究组织“阅读 / 思考与写作”，资源统一在中央标签栏打开；资料、摘录、卡片、白板和文稿可以往返操作。
- 添加资料统一入口，支持本地 DOI/arXiv 识别、无全文条目和就地补 PDF；同文件复用原资料，补全文保留条目身份。
- 增加摘录整理、卡片找依据、出处链和结论补引用，允许从文稿回到原文核查。
- 新建研究时创建或关联本机目录，右侧本机助手沿用同一目录，切换研究后分别恢复输入与材料。
- 研究目录的 `Papertrail/` 自动保存真实 PDF、图片、摘录、卡片、白板、文稿、可读对话和结构化数据；提问前等待最新文件保存。外部修改保留并暂停覆盖，写入失败可重试。
- 会话归档保留原生 Session ID 与 Codex 续接命令；已通过一次真实 Codex 文件读取、回答及同目录会话发现/读取验证。
- 重写 README，集中说明安装、上手、目录、会话、备份与开发运行方式。

## 已验证

本机前端单元243项、服务端178项、桌面协议16项、浏览器85项、打包桌面9项通过；最后的界面调整后重跑相关浏览器与打包桌面检查。真实 Codex 探针使用合成材料，未使用用户研究。详细证据见[研究目录验收](../verification/research-directory/README.md)和[知识链路验收](../verification/knowledge-flow/README.md)。

macOS arm64 已实际安装并验证从0.1.1升级，保留原用户数据与升级前备份。跨平台构建和打包应用的远程 CI 结果以本 Release 关联工作流为准，不能用本机 macOS 结果代替 Windows/Intel 证据。

## 下载与迁移

- macOS arm64 / x64：选择对应 `.dmg`；也提供对应 `.zip`。
- Windows x64：运行 `Papertrail-0.1.2-windows-x64-setup.exe`。Squirrel 的 `.nupkg` 与 `RELEASES` 作为配套元数据保留。
- 使用 `SHA256SUMS` 核对下载完整性。模型凭据不包含于安装包。
- 正常升级保留应用资料，仍建议先通过“设置 → 工作区备份与恢复”导出完整 ZIP。浏览器、桌面及不同设备之间用 ZIP 迁移；恢复是整库替换。

- DOI/arXiv 仅本地识别；Agent 联网检索、自动下载全文和结构化候选入库仍在后续范围。
