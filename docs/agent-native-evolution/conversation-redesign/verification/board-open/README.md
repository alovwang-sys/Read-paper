# 白板打开与提问验收

本目录验证可点击原型的白板入口、正文编辑、卡片移动与提问返回路径。使用本地合成卡片和固定示例回答；不验证生产 Excalidraw、真实 AI 调用、原生助手连接或磁盘持久化。刷新页面后示例状态会恢复。

运行方式（先在项目中启动 5173 端口的开发服务）：

```sh
node docs/agent-native-evolution/conversation-redesign/verify-board-prototype.mjs
```

检查包括：

- 1440×900、1280×800、1024×800 实际进入关系画布，显示三张卡片与连线，正文可独立打开。
- 编辑卡片正文，返回白板再打开，内容保留。
- 拖动卡片后连线随之改变；打开正文、发问及返回白板后位置保留。
- “加入提问”保存当时的正文快照；后续编辑不自动更换已选上下文，发送后可以回到白板并看到后续编辑。
- 记录浏览器运行错误，阻止并记录非本地请求。

本轮定稿验证 **6/6 通过**，浏览器运行错误 **0**，非本地请求 **0**。拖动位置以卡片自身的设计空间坐标及连线路径核对，避免把画布适应视口后的缩放差异误判为位置丢失。
