## 已验证的用户路径

1. 1440×900、1280×800、1024×800 均只有一个聊天输入，权限、语音与发送按钮在视口且中心实际命中；中央资源与侧聊天不重叠，页面无横向溢出。
2. 研究资料初始只有 A，全局有 A+B；浏览全局不关联 B，明确“加入本研究”后研究内才可见 B。
3. Codex 显示研究工具能力，Claude Code 显示仅文字问答；权限说明中没有虚构的可调三档，轻弹层锚定于输入工具上方，没有暗幕。
4. 语音示例只追加草稿，不发送、不替换白板。
5. 侧边、浮窗和主聊天移位保留同一会话与草稿；连续键入保持焦点；浮窗可拖动。
6. PDF 旁发送立即清空已发输入，资源留在原处，合成答案仍留在侧边。
7. PDF真实选文后点击“提问”创建具名局部会话并出现在左侧，浮窗与选中文字边界不重叠；继续到侧边保留同一列表项、输入和材料。
8. 关闭进行中的浮窗不停止任务；完成后列表显示未读，PDF 不被替换；再次打开能看到完整合成答案。
9. 两个阅读视图分别保持自己的页码（从 12 / 12 分别改为 13 / 11）；1024px 主动放大或恢复后仍保留两边位置。1157px 同时打开双页与侧聊时折叠左导航，两页各 398.5px，输入可点击，页面无溢出。
10. 用真实 Excalidraw 工具绘制矩形并问选中内容，局部 PNG 解码为 262×160，预览文字只描述所选图形；改选另一个新图形不会自动扩充已有材料或更换快照。局部提问会保留可用的浮窗或侧聊位置，以免覆盖原选区。
11. Claude Code 含图时阻止示例发送，保留草稿、材料和已有消息。
12. 侧聊、浮窗、主聊都能打开标题菜单；搜索只显示匹配会话，不自动跳转。菜单中新建保留当前白板与浮窗位置，只有一个新空输入。
13. 从菜单在 A/B 间切换恢复各自草稿；新会话为空，原会话草稿和旧消息保留。
14. “带上当前选区”取消时不复制材料，启用后复制快照；往返重复携带不重复增加材料，不搬运旧消息。预览仍显示加入时的原文。
15. A 发出后通过菜单切到 B，迟到回答只进入 A；B 的草稿和已有消息不变，A 有未读提示。
16. 推荐函数只考虑同研究、排除当前会话；来源相同或至少两个有效词重合才相关，单词重合不相关；材料去重键忽略实例 ID 和选区元素顺序，但不同正文不会误去重。实际界面可显示“相关会话”，最多三条且不自动切换；无相关时显示“最近会话”。
17. 同一场景与选区连续经过 1440px 单页侧聊、双页侧聊、1157px、1024px、关闭侧聊、恢复侧聊、浮窗、关闭浮窗、恢复侧聊九个状态；六个原生工具（选择、矩形、箭头、自由书写、文字、橡皮）的父 label 都留在白板容器边界内，关闭浮窗后均可实际命中。332px 白板中的工具为 26×30px，未裁出边界。结束时原选区仍可提问，PNG 解码仍为 262×160，未记录 ResizeObserver loop 或运行错误。为验证或截图没有改变画布缩放与平移。

通用“浮窗继续”打开时允许覆盖另一工作面，部分背后工具可能被浮窗遮挡；该状态只验证工具 label 没有裁出容器，不宣称背后的每个工具都能点击。关闭浮窗后才断言六个工具全部命中。PDF 或白板“问选区”另有锚点避让／侧聊退让，这些路径继续由前面的检查覆盖。

## 边界

回答是定时合成文字，没有连接真实 LLM；语音是写入草稿的示例，没有录音或转写服务。PDF 是合成内容，分屏是隔离布局示意；预览只演示最多两组标签，正式实现需沿用既有递归窗格。白板编辑和 PNG 导出使用真实本地 Excalidraw 实例，但这不代表已经接入正式产品、持久化、真实研究工具或安装包。未运行既有正式产品完整套件。
