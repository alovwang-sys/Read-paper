## 已验证

- 1440×900、1280×800、1024×800 无页面横向溢出，输入、助手切换与发送均在视口；会话条目 36px、单行。1024px 折叠左侧导航，聊天与 360px 原文并列，边界不重叠。
- 提交立即进入中央当前会话并清空输入；约 1.8 秒后显示合成回答。普通切 Codex / Claude Code 不换会话，保留草稿，旧回答的助手标签保持不变。
- 会话之间独立草稿；引用打开右侧第 12 页，全文进入中央同页，加入材料后发送回会话，并可返回该页。
- 白板材料发问后可返回原白板内容；编辑文稿后发问，再返回时修改内容保留。
- 发送后切另一会话或同会话白板，迟到回答不替换当前主区；原会话有未读标记，白板上的“查看新回复”可回到答案。
- 合成失败后原轮重试不重复追加用户问题，保留后续输入；助手菜单支持 Esc / 外部点击关闭；OpenCode 连接为明确的模拟行为。
- 旧 Codex 原生记录换其他助手时建新会话，复制输入，旧会话内容与草稿仍可返回。
- 收录按钮完成后禁用，资料库增加一条候选，白板卡片数不变。
- 1024px 参考打开时输入和发送按钮实际命中，发送后保留右侧原文，中央答案可见。
- 900 / 901 / 1100 / 1101 / 1247 / 1248px 各断点均实际打开引用并发送。900px 为覆盖参考，输入保留在前景，发送收起参考；901–1247px 折叠左栏、主区与参考并列；1248px 保留左侧 224px 导航。并列时主区与参考边界不重叠、参考宽 360px，输入和发送按钮中心命中自身。
