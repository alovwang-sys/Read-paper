# 会话归属：研究会话与对象讨论

2026-10-23。回应用户的问题：在卡片、原文里提问，算不算"会话"？全放进会话列表会挤满，不放又找不到；大小会话怎么区分，一个研究里的会话该平铺还是分类，要不要用模型判断新建还是继续。

## 一句话

**会话按"问的是什么"归属，不按大小分。** 问整个研究，进研究会话；问某个具体东西（一段原文、一张卡片、一块白板），进这个东西自己的讨论，讨论挂在它身上。

不按大小分，是因为提问时还不知道这次会聊两句还是二十句；问的是什么，在提问那一刻就已经确定。所以可以按固定规则直接把问题送到对应的地方，不需要模型猜，也不需要用户先选。

## 两类会话

| | 研究会话 | 对象讨论 |
| --- | --- | --- |
| 问什么 | 跨资料的问题、研究计划、写作 | 这段原文、这张卡片、这块白板 |
| 从哪发起 | 左栏"新会话"、聊天输入框 | 原文选区"提问"、白板／卡片"问 Agent" |
| 上下文 | 用户明确加入的材料 + 本会话历史 | 对象本身（原文另附文章简要）+ 本讨论历史；**不继承任何研究会话** |
| 放在哪、怎么找 | 左栏会话列表 | 在对象上：原文标记、卡片和白板节点的讨论数；另有"全部讨论"汇总 |
| 数量 | 少，几个到十几个 | 多，但不进入主列表 |

"小会话"不需要单独成为一种类型。两句话的对象讨论本来就挂在对象上，不占列表；两句话的研究会话放久了会自动收起（见下文）。

## 路由规则：固定、可预期、可改

1. **从对象发起，就进入这个对象的讨论。** 已有讨论就接着问，没有就新建。同一张卡片总是回到同一条讨论，这就是"离这张卡片最近的会话"。
2. **白板多选或自绘内容，进入这块白板的讨论。**
3. **在聊天框直接输入，进入当前会话。**
4. **发送前显示落点，并允许改。** 输入框上方显示"将发到：卡片《X》的讨论 ▾"，可以改成"新开讨论"或某个研究会话。

不用决策模型判断"新建还是继续"：猜错一次就会污染上下文，用户也无法提前知道结果。固定规则、显示落点、改一下只需一次点击，比模型猜更可靠，也更好理解。

## 讨论之间怎样流动

- **升级：** 对象讨论聊深以后，可以"升为研究会话"，固定到左栏。原文旁问答已有 `promoted` 字段，沿用即可。
- **带入：** 研究会话需要某条讨论的结论时，用"带入会话"把那条回答作为带引用的材料加入，不合并两边的历史。上下文只能通过这种显式操作转移，不会互相污染。
- **沉淀：** 讨论的结果整理成卡片；卡片放上白板成为节点；节点上可以继续提问。这样形成闭环。

## 组织方式：平铺还是分类

- **研究会话平铺。** 按最近活动排序，可以置顶；14 天没有活动的自动收进"更早"。不做文件夹，因为对象讨论不再挤进来，列表本身就短。
- **对象讨论不需要手工分类，对象就是分类。** 白板（知识地图）本身就是讨论的目录：每个节点挂着自己的讨论。这也就是"针对地图上每个点深入剖析"的思路。
- **三个找回入口：** ① 在对象上看讨论数或原文标记；② 左栏"讨论"按资料、卡片、白板分组，并且可以搜索；③ `⌘K` 全局搜索覆盖全部会话。

```
左栏                                  白板节点
研究工作台                            ┌──────────────────────┐
本研究资料                            │ 观点卡片              │
会话                         ＋       │ 完善架构前需要核对…   │
  比较三种后训练方法                  │                      │
  写结论初稿                          │ 0 条依据 · 💬 3 · 打开│
  更早（3）▸                          └──────────────────────┘
讨论（12）▸   按资料／卡片／白板分组
最近打开
```

## 落地顺序

| 步骤 | 内容 | 状态 |
| --- | --- | --- |
| 1 | 白板只选一张卡片 → 进入该卡片的讨论；其他选择 → 进入本白板的讨论；一次点击进入并聚焦输入框。会话新增 `anchor` 字段 | **已实现**（本轮） |
| 2 | 带 `anchor` 的讨论和未升级的原文旁问答移出左栏主列表，改进"讨论"分组；卡片、白板节点显示讨论数，点击即进入 | **已实现** |
| 3 | 输入框显示"将发到"落点，可以一次改到别处 | 待确认 |
| 4 | "升为研究会话"和"带入会话" | 待确认 |
| 5 | 研究会话自动收起旧项 | 待确认 |

第 2 步的实际表现：

- 左栏"会话"只列研究会话。"讨论（N）"默认收起，当前会话是讨论或正在搜索时自动展开；按卡片、白板、各篇资料分组，原文讨论显示页码和摘录开头。标题下拉的会话选择器也分成同样两段。
- 讨论数按问答轮数计算，只在至少有一轮时显示。卡片布局里卡片底部的 💬 数字点一下即进入；白板工具栏显示"白板讨论 · N"。
- 绘图模式下，Excalidraw 的交互画布盖在嵌入的卡片上方，卡片要先激活才能点击里面的按钮（原有"打开"按钮也是如此）。因此卡片上的数字只用来提示，可点击的入口放在选中卡片后底部的操作栏里（"讨论 · N"）。
- 原文旁问答点"在右侧继续"会升级（`promoted`），回到主列表，沿用原有逻辑。资料节点（PDF）暂不显示讨论数：同一篇论文的不同位置各有一条讨论，点一下应该进入哪一条还没有定。
