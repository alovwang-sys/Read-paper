## 一条连续的操作路径

选中文字，或点阅读器上方「框选区域」后拖框 → 原文附近出现 **提问 / 翻译 / 摘要卡片 / 更多**。无需滚到论文底部，也不用先去右栏找入口。

| 动作 | 当下看到什么 | 再次回来 |
| --- | --- | --- |
| 提问 | 原处浮窗输入，回答留在同一会话；可主动切到侧边或完整对话 | 点原文标记，从记录打开原会话 |
| 翻译 | 同一个选区浮层展开译文，不创建聊天 | 标记中找回译文；可另存翻译笔记，原文保持只读 |
| 摘要卡片 | 只总结当前选区，在已有卡片浮层编辑并确认保存 | 标记可找回草稿或已保存卡片 |
| 更多 | 保存原文摘录、手工制作卡片、高亮 | 都关联同一原文位置，人工高亮有填色 |

选中、打开提问草稿不算实际提问，不留操作标记。提交问题、生成翻译、生成摘要草稿、保存摘录等实际动作才记入。失败与停止也保留记录，不能让出过错的位置消失。页边只保留一个轻量计数，详细结果按需展开。

## 同一处和不同位置

- 文字锚点：文件 hash、从0开始的页索引、文字起止偏移。原生选区的段落换行保存在原句快照，定位仍用 DOM/PDF 文字偏移，不能拿显示字符串的长度冒充位置。
- 区域锚点：文件 hash、页索引、归一化矩形。**点已有区域标记**是继续同一处的可靠入口；重新画框按新位置处理，不进行近似合并。
- 相同精确文字位置再次提问，或从标记进入，继续此处会话；其他位置建立独立会话。重叠不等于同一处。显式「新会话」仍可另起话题。
- 原文标记的实体是位置锚点，不能拿摘录或卡片 ID 代替。一个位置可有关联会话、翻译、多个卡片；删除白板摆放不能删除这些来源。

当前内存原型同一文字位置复用最近会话。显式新会话时是否携带材料，沿用已有会话选择器。相近选区候选建议后置，先验证精确位置与标记回查是否足够。

## 一篇文章一份底座，各处会话各自独立

这里称 **文章简要**，与官方 abstract 和「选区摘要卡片」分开。文章简要记录研究问题、方法、主要发现、限制和必要术语，**只是背景，不充当引用证据**。

首次实际提交本篇问题才准备简要，翻译与选区制卡不等待它。准备中可选「先只按选区回答」，这不取消其他会话要共用的简要任务。同篇并发首问共用一个生成任务；停止一个局部回答也不取消其他局部的等待。

默认新位置请求 = **文章简要 + 当前原文选区 + 这个局部会话自己的历史**。其他位置的聊天、整篇原文和全局资料库不自动追加。用户明确添加的材料仍逐项可见。

输入区只放一枚简要标签与「本处选区」，点开可查看实际正文、覆盖页与生成来源。每个已提交问题有「本轮材料」，能查看这轮用的简要、原句与此前历史，不能只显示一个抽象的“上下文已连接”。

| 时刻 / 状态 | 处理规则 |
| --- | --- |
| 点击提交 | 冻结原文位置、当时的原句/图像、显式材料与本会话历史 |
| 简要未生成或正在生成 | 首次请求等待共享任务；允许本轮只用选区 |
| 请求开始生成回答 | 冻结简要正文、版本和覆盖范围，或明确记为本轮未带简要 |
| 其他会话完成 / 简要后来就绪 | 不修改已经发出的请求，不把回复挪到当前另一会话 |
| 简要失败 | 保留原问题与位置，显示失败，可重试；不得静默编一份摘要 |
| 正式版文档或提取结果变化 | 用文件 hash + 提取版本 + 简要 schema + 提示版本识别；旧请求保持旧快照，新版由明确动作启用 |

切换助手不需要重新生成同一份文章简要；生成模型另记来源。正式接入时建议简要控制在约1500 tokens内，保留可用上下文给选区与局部历史；实际预算由连接的上下文容量和输出预留决定，超限不能偷偷删原句或串入其他会话。此预算与真实模型质量尚未在原型中验证。

## 文字与图形的能力边界

有文字层的框选，译文只基于能核对的文字。无文字层时不假称 OCR 成功，翻译禁用。区域提问和区域摘要需要支持图片的连接，不能因为切换了助手就悄悄降级为只发文字或空内容。

正式产品已有 PDF 画布真实裁图、资产 hash 和图片能力检查，应复用；文本位置还需补足稳定偏移/前后文，以区分同页重复原句。区域没有文字时保留裁图来源，不生成假的原文引句。

## 本轮与正式接入的分界

当前交付只修改隔离工作区原型及其验证，不改已安装的0.1.14。原型是真实鼠标选字/拖框、就近浮窗和内存实体联动；翻译、摘要、回答与简要为合成示例，**没有调用模型、提取真实 PDF、OCR 或裁切真实图像，刷新会重置**。简要示例仅覆盖合成第12页 / 共20页，不能称为全文简要。

本次完成4轮真实 Claude Code 讨论，实际看图7张。采纳视觉反馈后，文章简要在当前聊天内展开，标签明确“仅第12页”；摘要来源说明独立于可编辑正文。最终[选区专项8项](verification/workspace-selection-context/README.md)、[会话回归17项](verification/workspace-preview/README.md)、[集合9项](verification/workspace-notes-access/README.md)和[拖拽6项](verification/workspace-tabs/README.md)共40项通过；[简要缓存逻辑](verify-paper-brief.mjs)验证并发共享、失败重试、缓存身份与不可变请求快照。只计本轮实际通过的范围。

正式接入仍需：持久化 SourceAnchor/Activity/PaperBrief 与迁移；复用共享 ReaderPopover 和原生会话；真实全文覆盖统计、token预算与引用校验；图像发送及视觉能力；长文、重复原句、密集标记、失败重试和刷新恢复验收。不能把本原型通过等同于这些能力完成。
