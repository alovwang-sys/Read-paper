# 卡片与摘录：从文末搬到固定入口

2026-10-23。用户指出上一版把保存项放在论文底部，查卡片必须滚动，操作仍然割裂。本次修订只更新[布局预览](http://127.0.0.1:5173/docs/agent-native-evolution/conversation-redesign/workspace-preview.html)，正式软件保持原状。

## 取回入口与阅读位置分开

- 工作区顶栏固定一个“卡片与摘录”入口；论文、白板、文稿、完整聊天中都可打开。左侧“研究笔记”仍是原有文稿，保留不删；全局资料浏览保持独立会话。
- 删除论文底部的保存项集合。保存后只出现“已保存 · 查看”；点击“查看”直接定位刚保存项，提示消失后仍可从顶栏找回。
- 集合浮窗锚在中央工作区内，独立滚动，不改变论文阅读位置、窗格树或左栏状态，也不遮盖右侧聊天。它可以临时覆盖中央部分内容；点击出处会收起浮窗，回到原文。
- 列表与卡片编辑复用同一个浮窗。编辑结束返回原承载，关闭保留未保存稿，不叠第二个卡片窗口。

## 一份实体、明确范围

默认“本研究”，用户可显式切到“本篇：样例论文A”；关闭再开保留范围、搜索词与列表位置，不随当前焦点悄悄换范围。只有点击保存提示中的“查看”，才清除可能遮住结果的搜索条件、切回本研究并标记新条目。

摘录保留完整原文、文献 ID 和从0开始的页索引；卡片正文与依据独立，沿证据关联归属论文。同句摘录复用，多处查看同一份实体。卡片与摘录仍分别标注，列表不把它们混为一份正文。

草稿以 `cardId` 或 `new:excerptId` 区分。切条目、关闭集合、回原文均保留草稿；再次从同一摘录制卡会恢复同一份未完成稿。新建制卡先保存/复用原文证据，与正式阅读器已有行为一致。

点击出处由父级定位：当前窗格已有论文 → 另一窗格已有论文 → 在当前窗格新开。已有标签不复制、不移动，另一边的页码和滚动保持；定位指令在目标挂载后执行一次并消费。找不到可用来源时，集合保留并显示原因。

## 最小改动与正式承载

新预览只增加一个集合浮窗组件，沿用父级 `excerpts/cards`、卡片编辑器、原文匹配和已有标签树。没有增加第三列、类型标签栏或无效的“在标签中打开”按钮。

源码审计表明，正式研究卡片/摘录可通过 `openResearchView(researchId, 'cards'/'excerpts', paneId)` 接回资源窗格；`openCollection('cards')` 会进入全局资料库，不能用于替代本研究集合。本篇筛选需要沿卡片证据关联派生文献归属。多篇固定笔记标签需要明确视图身份，不能只靠全局“当前论文”；本次不提前实现这套扩展。

[3轮真实 Claude Code 讨论](review/reader-notes-placement/README.md)记录底部路径诊断、三种承载取舍、草稿与定位反驳；最后一轮实际Read四张图，结论无必须修的视觉阻断。[新增9项集合专项](verification/workspace-notes-access/README.md)、既有17项交互与6项拖拽均通过。1280×540下实际阅读滚动69px、集合滚动420px相互独立，九源起止hash稳定。旧的[9项底部列表验收](verification/workspace-reader-notes/README.md)保留为历史，不能当作本次新入口已验证。

本轮仍使用合成论文、内存笔记与示例回答。新浮窗没有接入正式卡片集合、白板摆放、磁盘恢复或真实模型；本篇/本研究多文献过滤有纯函数检查，不冒充真实多篇 PDF 或研究切换验收。
