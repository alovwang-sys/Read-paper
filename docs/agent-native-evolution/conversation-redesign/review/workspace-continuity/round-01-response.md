# 会话与工作面连续：第1轮方案

## 核心规则：互补位

**主区和右栏互补：会话与原文一个在主区，另一个就在右栏。** 卡片浮窗只是临时借用同一个输入，不是第三个位置。

- 主区是会话时，右栏显示引用原文（保持现状）。
- 主区是 PDF、白板或文稿时，右栏显示同一会话。
- 发送不再切换 `st.view`，资源页始终停在原处。

右栏顶部只放一个 `⇄` 图标，用于把会话和资源对调。不增加布局按钮。

## 1. 资料入口

左栏底部拆成两个入口，`RES` 中删除 library：

- **「本研究」**：一个入口，下分「资料 / 成果」两个页签。只包含当前研究的 PDF、卡片、白板和文稿。
- **「全局资料库」**：图标不同，位置放在最底部。在主区以标签页打开，抬头写「所有研究」。条目只有一个动作「加入本研究」，加入的是引用，不复制文件。

## 2. 唯一输入工具行

```
[卡片:定义 ×][PDF p3 选段 ×]        ← 有材料才显示
┌────────────────────────────────┐
│ 输入…                           │
├────────────────────────────────┤
│ + 助手▾ 只读▾           🎙 ➤   │
└────────────────────────────────┘
```

- 权限选项按供应商实际能力显示，不支持的选项不出现。
- 选「完全访问」需要二次确认，标签变色。只在当前会话有效，新会话不继承。
- 发送时冻结权限快照，运行行显示「只读」等小字。之后再调整只影响下一次运行。
- 语音入口固定在发送键左侧。

## 3. 三个场景

```
会话主页 1440
│左224│   会话(主)        │原文 360│

资源工作 1440 / 1280
│左224│ PDF │ 白板(分屏)   │会话 400/360│
                           └ 输入在此

卡片浮窗
│左│ Excalidraw ┌浮窗420┐  │会话(输入已借出)│
│  │   [卡]────│正文编辑│  │
│  │           │输入    │  │
```

- **引用**：在侧栏会话里点引用，会在主区定位到原文。文档已打开就跳到对应分屏，否则新开标签，不替换当前分屏。
- **输入移动**：搬的是同一个输入实例，草稿、光标和选区都保留。如果正在用输入法组字，等组字结束再移动。原位置只显示一行灰字「输入在卡片中」，不另建话题。
- **1024 宽度**：左栏收成 56px 图标轨，侧栏会话改为 340px。主区有分屏时，侧栏会话收成一条带未读点的窄轨，展开后只覆盖右侧那个分屏，不叠抽屉。关闭后资源回到原来的滚动位置和选择。

## 4. 保留分屏与绘图

- 主区标签页和多页面分屏保持原样。侧栏会话是主区外的一列，不占分屏格。
- 白板继续使用正式的 Excalidraw，人工连线照常可用。原型里的 3 张卡只能算占位，不能当成已等价于现有绘图能力。
- 框选后浮出「问所选(n)」，点了才把材料标签加入输入，不打开浮窗。答复写入会话并标注框选目标。「放到白板」需手动点击才执行。

## 5. 浮窗编辑与局部问答

- **打开**：双击卡片，浮窗贴在卡片旁边。编辑的是同一个卡片实体，自动保存。
- **加材料**：浮窗里点「问这张卡」时，才把卡片正文作为可见材料标签加入，并把输入借到浮窗。只是打开浮窗不算授权。
- **结果位置**：答复写入同一会话历史，带「→卡片」标记。浮窗只显示最近一条，附「在会话中查看」。AI 的修改以差异形式呈现，点击才应用。
- **关闭**：按 Esc 或点击外部。编辑不丢，运行不取消，输入带着草稿回到侧栏。迟到的答复只落到该会话，并在卡片上显示小点，不弹窗、不抢页面。

## 不同意的两点

- **第 3 点**：我不认为侧边聊天应该和右侧「参考原文」并存成第四区域。资源工作时，原文已经在主区，右栏再放原文是重复，所以改为互补位。
- **第 5 点**：「就地问答」不应让浮窗拥有自己的对话历史。浮窗只是借用输入的位置，否则就是隐形话题，和一个会话一份状态的约束冲突。

## 不确定之处

- 1024 宽度下覆盖分屏的做法，需要 Codex 确认分屏组件能否局部遮挡。
- 各供应商的权限选项能否统一归成三档，需要依据代码审计确定。
