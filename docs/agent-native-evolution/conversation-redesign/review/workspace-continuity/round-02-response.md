## 三、哪些动作创建会话，哪些只是换位置

**明确创建局部会话（自动命名，进入会话列表）：**
- PDF 选段浮窗中发问（沿用现有逻辑）
- 卡片浮窗中点「问这张卡」，名称为“卡片·标题”

**沿用当前会话，不新建：**
- 侧栏输入框发问
- 白板框选后点「问所选」：材料标签加入侧栏输入

**只换位置（同一 ID）：**
- 浮窗点「右侧继续」：侧栏的活动会话切换为该局部 ID。进行中的请求、草稿、选区一起搬过去，不得写 `agentWorkbench=false`。原研究会话仍保留在列表中。

## 四、互斥与保留规则

- **一个 ID 只在一处呈现。** 同一会话 ID 同一时刻只有一个承载位置（主区 / 侧栏 / 浮窗），每个位置配一个输入实例。
- **主区与右栏不重复。** 主区是某个会话时，右栏不再显示同一会话。
- **引用不覆盖聊天。** 右栏正在聊天时，点引用会在现有资源窗格新开标签，原资源的位置保留，不覆盖已有分屏。
- **浮窗最多一个。** 打开另一张卡会替换浮窗，原局部会话保留。
- **关闭浮窗时：** 卡片编辑已自动保存，运行不取消，草稿随会话保存。迟到的答复只在卡片上显示一个小点。不用常驻说明文字。

## 五、三种宽度

- **1440**：左栏 224 | 主区（用户分屏树）| 右栏 360–400。
- **1280**：左栏可收起，右栏 360，分屏树不变。
- **1024**：分屏树结构不变。当前聚焦窗格放大，其余窗格暂收为标签，变宽后恢复。右栏会话保持 360。点引用时原文以浮层显示，不遮挡当前窗格和输入。

## 六、最小可点击演示

演示使用隔离的合成数据，不接触正式生产数据。

1. **1440 资源工作**：PDF 与白板分屏，右侧会话。发送后视图不变。
2. **引用跳转**：在侧栏点引用，在资源窗格新开标签，原分屏保留。
3. **卡片浮窗**：双击卡片编辑。点「问这张卡」后，会话列表出现局部会话。模拟流式回复进行中点「右侧继续」，请求不中断，草稿保留，仍为研究模式。
4. **迟到答复**：按 Esc 关闭浮窗，之后答复到达，卡片出现小点。
5. **工具行**：切换三类供应商，工具行显示随之变化。
6. **资料入口**：两个入口显示不同的数据集。
7. **宽度切换**：1024 下聚焦窗格放大，变宽后分屏恢复。

**不在演示范围内**：双聊天分屏（需要新的视图契约）、workspace-write、替换生产 Excalidraw 场景。
