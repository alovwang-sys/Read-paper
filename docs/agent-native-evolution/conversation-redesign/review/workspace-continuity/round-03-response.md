# 第3轮收口：工作面连续最终方案

> 说明：本轮只依据第2轮答复和 Codex 反驳形成文字定稿。我没有看图，也没有操作过 UI。演示环境是隔离的合成原型 `workspace-preview.html`，上一组的 `prototype.html` 保留不动，正式应用的数据、Excalidraw 场景和资料库都没有改动。视觉问题留到第4轮看图时复核。

## 一、接受与回撤

- **回撤**“每个位置配一个输入实例”。改为只有一个逻辑 composer。
- **回撤**“1024 下自动把其余窗格收成标签”。改为由用户主动放大、主动恢复。
- **回撤**“迟到答复只在卡片上显示小点”。改为在左侧会话列表的同一 ID 上标记未读，卡片小点只作辅助。
- **接受**：演示回复是定时合成的，不代表真实模型流式输出已经验证。
- **接受**：用户可以从菜单显式切换到另一个已有会话，但默认绝不串话。

## 二、最终 5 点落位

**① 资料**
- 全局资料库显示全部资料；本研究视图按关联关系过滤，两者是真正不同的数据集。
- 在研究页“添加” = 收录进全局 + 显式关联当前研究。
- 在全局页“加入本研究”只建立关联。
- 浏览和预览不改变任何关系。
- 卡片在浮窗里编辑的是同一个实体，不跳页。

**② 权限与语音**
- 工具行只按供应商的真实能力显示：
  - 研究 Codex：一个固定的短标签「研究工具」。
  - 经典 Codex：只读 / 完全访问，不画 workspace-write。
  - Claude / OpenCode：只显示文字，不继承 Codex 的权限。
- 「语音」带文字标签，只调用系统听写写入草稿，不录音、不上传。
- 权限说明只在用户需要做选择时出现，主界面不写技术讲解。

**③ 资源、侧聊与多页**
- 主区是资源时，右栏显示会话；主区是会话时，右栏显示参考原文。
- 发送不切换 `st.view`。
- 点引用时，在资源窗格新开标签，不覆盖已有分屏。

**④ Excalidraw 框选**
- 复用真正的本地 Excalidraw 模块，使用原生框选，不重写画图器。
- 「问所选」的材料只包括：选中的元素、卡片正文、局部 PNG 和文字快照。箭头另一端的元素不纳入。
- 「问所选」沿用当前会话。

**⑤ 浮窗**
- PDF 选段或卡片上显式点「问这处」，会创建一个具名局部会话，并进入左侧列表。
- 「在侧栏继续」沿用同一个 ID，不得写 `agentWorkbench=false`。
- 关闭浮窗不终止请求，也不丢失编辑和草稿。

## 三、共享不变量

1. **一个 ID 只在一处承载。** 主区、侧栏、浮窗三处同一时刻只有一处显示该会话。
2. **只有一份输入状态。** draft、materials、request 只存一份，同一时刻只有一个活跃输入，其他位置移除或只读，不维护影子草稿。
3. **换位置不复制，也不中断。** 进行中的请求、草稿、选区一起搬运，焦点、选区和输入法状态也要保住。
4. **用户的分屏树只由用户改变。** 宽度变化可以先收起左栏，但不重排窗格。
5. **默认不串话。** 只有用户显式选择才会切换会话。
6. **界面不夸大能力。** 不把目标设计画成已有能力。

## 四、正式实施最小切片（按优先级）

**先改宿主和契约，再做 UI。** 否则每个位置都会自己复制一套导航和状态机。

| 顺序 | 切片 | 复用 / 独立验证 |
|---|---|---|
| P0 | 共享视图契约：会话承载位置（主区/侧栏/浮窗）+ 单一 composer 状态的归属 | 复用现有会话存储与请求服务。独立验证：请求跨位置不断流，`agentWorkbench` 不被重置 |
| P1 | 发送不切视图；引用在资源窗格新开标签 | 复用现有分屏树。独立验证：分屏树前后一致 |
| P2 | 「在侧栏继续」同 ID 搬运；关闭浮窗后的未读标记 | 复用局部会话逻辑。独立验证：焦点、选区、输入法状态，以及迟到答复的未读 |
| P3 | 工具行按能力显示 | 复用供应商能力声明。独立验证：每个供应商实际能做什么，以真实运行时为准，不以原型为准 |
| P4 | 资料两视图与关联语义 | 复用现有资料实体和文件。独立验证：浏览不写关联，添加不复制文件 |
| P5 | 「问所选」材料与快照 | 复用本地 Excalidraw 的导出能力。独立验证：PNG 裁剪范围、箭头不外溢 |
| P6 | 1024 下的主动放大与恢复 | 纯 UI，放在最后 |

**不做**：通用布局系统、产品层多 agent、新的数据模型、双聊天分屏。
