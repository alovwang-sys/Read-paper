## 必须改变（4 项）

**1. 04：原文覆盖层盖住了对话内容。**
- 可见问题：右侧 664–876px 这一段文字被硬切，例如“实验中同时改变了同义词扩展，”后面直接断掉。用户自己的提问气泡也被整块盖住，y≈300–420 只剩一片空白。“收录文献”按钮也看不到。这看起来像布局坏了，而不像一个浮层。
- 修法：1024 宽度下打开原文时，改为推挤布局，不再用覆盖层。左栏已经收成汉堡按钮，对话区有 664px，正文和输入框都改成左右各留 24px，宽 616px，左对齐。原文栏保持 360px，并加左边线 1px #E6E6E1。这样不会回到我第 4 轮担心的“挤聊天”问题。

**2. 02、03、04：消息区底部被硬切。**
- 可见问题：y≈650 处，“检索扩展的跨库对照”和“收录文献”按钮被横向切掉一半，和输入框之间只隔约 12px，看起来很粗糙。
- 修法：让消息区一直延伸到输入框下面。底部留白设为“输入框高度 + 32px”。输入框上方加一条 32px 的渐变，从透明过渡到 #FFFFFF。

**3. 02–05：引用样式不统一。**
- 可见问题：第一轮答复的引用是“样例论文A · PDF第12页 ↗”胶囊；第二轮却是“[样例论文A·PDF第12页]”，带方括号、没有间距，像漏出来的 Markdown 原文。前面的标签一处写“核对依据”，一处写“依据”。
- 修法：统一成一种胶囊。字号 12px，背景 #EAF2EA，文字 #3D6B4F，内边距 2px×8px，圆角 4px，末尾带 ↗，去掉方括号。标签统一用“依据”，颜色 #6B6B66。

**4. 03：助手菜单的状态列没对齐。**
- 可见问题：Codex 的“已连接”在右边；Claude Code 只有 ✓；OpenCode 的“未连接”在中间，后面再跟一个“连接”按钮。三行三种格式，读起来很乱。
- 修法：菜单宽 220px，每行 36px。名称左对齐，右侧固定一列 56px：当前助手显示绿色 ✓；已连接的什么都不显示；未连接的只显示文字按钮“连接”（13px，#3D6B4F）。删掉“已连接”“未连接”两处文字。
