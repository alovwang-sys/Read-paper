本次共4轮成功讨论，2轮视觉讨论实际读取7张图。第1、2轮禁用所有工具、MCP 与会话保存；第3、4轮仅开放 Read，输入限定隔离临时目录中的指定截图，状态文件记录成功图像读取及每图 SHA-256。原始事件仅保留必要结构，未保存思考内容或 base64。CLI discussion 的一轮指一次成功的请求/答复，不把图像读取工具回合计为多轮讨论。

采纳第3轮建议：文章简要改在当前聊天消息区内展开；标签改成“仅第12页”；摘要来源说明移到不可编辑位置，示例正文做压缩改写；去掉历史重复计数并显示细滚动条。独立验收随后发现展开简要会滚到中段，进一步改为定位简要顶部。

未采纳：删除语音、图片和权限入口。用户此前明确要求这些能力，局部聊天也允许**显式**添加材料；上下文固定的是默认绑定位置与其他局部历史隔离，不是禁止用户补充材料。保留明确关闭按钮，兼顾鼠标、键盘与小屏操作。

Claude 的结论是设计/静态视觉意见，不是它运行了应用。实际鼠标、发送、来源与快照行为由[本轮独立验收](../../verification/workspace-selection-context/README.md)验证；正式模型、真实 PDF 和刷新持久化均未完成。

非阻断建议暂留：长简要在消息区滚动时，下沿贴近输入框，后续可在实际长文试用中评估渐隐提示。当前标题与收起入口均可见可点，且未添加新的浮层。
