# 第4轮：缺陷认领与视觉规则（仅基于文本反馈，未看截图）

## 一、我认领的错误

1. `#R`/`.rl{display:flex}` 覆盖了 `hidden` 属性；同时 grid 用的是裸 `1fr`，没有设 `min-height:0`。这是布局错误，不是取舍。
2. `run` 只判断 `st.cur!=s.id`，漏了"同一会话但不在 chat 视图"的情况。
3. 回复完成时无条件 `scrollIntoView`，会打断正在上滚阅读的用户。
4. 研究 select 退回成原生表单；所有按钮同为描边小按钮，没有层级。
5. 1024 宽度下用 `margin-right` 挤压主区；打开 PDF 就隐式加入资料。
6. `keep` 把内容写进白板，却显示为"收录"。
7. 资源页的解释句是多余的。

## 二、最小行为修正

```css
[hidden]{display:none!important}
#G{grid-template-columns:240px minmax(0,1fr) 360px;grid-template-rows:minmax(0,1fr);min-height:0}
#G.nr{grid-template-columns:240px minmax(0,1fr)}
#M,#R{min-height:0;overflow:auto}
@media(max-width:1100px){
 body.ro #M{margin-right:0}
 #R{width:min(400px,92vw);z-index:20}
 #scrim{position:fixed;inset:0;background:rgba(20,20,20,.18);z-index:19}
}
```

```js
const nearBottom=el=>el.scrollHeight-el.scrollTop-el.clientHeight<80;
// 在 render 之前记录 follow=nearBottom(M)
if(st.cur!=s.id||st.view!='chat'){s.un=1}   // 左栏圆点 + 资源页“返回会话”旁的圆点
else if(follow){scrollToEnd()}
else{showJump()}                             // 输入框上方居中的“↓ 最新回复”胶囊，点击后消失
```

- **资源页**：顶部只放一个"← 返回会话"。有新回复时，它右侧加一个 6px 圆点，点击后圆点消失。去掉那句说明文字。
- **1024 覆盖层**：头部只有"← 返回会话"和 ✕；按 Esc 或点遮罩都能关闭。
- **资料加入**：打开 PDF 不加入任何内容。参考行上提供"加入本轮资料"开关，必须明确点选。
- **收录**：候选行的按钮改为"收录文献"，写入 `library`。去重顺序是先 DOI，再"规范化标题+年份"。收录后按钮变为"已在资料中"（灰色，不可再点）。"加入笔记"作为独立动作，写入白板/笔记。
- **限制提示**：只在点击了不可用操作时，于该控件旁显示一行。

## 三、视觉参数

**基础**
- 字体：`-apple-system,"PingFang SC",sans-serif`
- 主文字 `#1f2328`，次要文字 `#6b6f76`，分割线 `#e7e5e1`
- 主区背景 `#fbfaf8`，左栏背景 `#f4f3f0`
- 唯一强调色：墨蓝 `#34558b`；悬停底色 `#eef1f6`

**标题**
- 会话标题 18px / 600，行高 26
- 主区内容最大宽 720px 居中，左右各 32px
- 标题与正文间距 20px

**正文**
- 15px / 400，行高 1.7，段距 12px
- 助手回复不加气泡
- 用户消息：底色 `#f1efea`，圆角 12，内边距 10px 14px，右对齐，最大宽 80%
- 引用标记：12px 强调色上标，悬停时显示底色

**输入**
- 容器圆角 14，1px `#e2dfd9` 边框
- 阴影：`0 1px 2px #0000000a, 0 6px 20px #0000000a`
- 聚焦时边框变为 `#34558b66`
- 文本 15px，行高 1.6，最少 3 行
- 底部工具行高 36：
  - 助手按钮：13px / 500 文字 + ⌄，无边框
  - 发送按钮：32px 圆形，强调色填充

**左栏**
- 行高 36，左右内边距 10，圆角 8
- 文字 14px `#3b3f45`
- 选中态：底色 `#e8e5df`，字重 500
- 未读：右侧 6px 强调色圆点
- 分组标题：12px / 600 `#8a8d93`，上间距 16
- 研究选择器沿用上轮的应用内按钮样式：h32，圆角 8，带 ⌄；弹出菜单圆角 10，带阴影

**参考**
- 每条上下 12px，条目之间用细线分隔
- 标题 14px / 500，最多两行截断
- 元信息 12px 次要色
- 摘录 13px，左侧 2px 强调色竖线，内边距 10
- 操作用 13px 强调色文字按钮

**按钮层级**
- 主按钮：填充强调色，h32，圆角 8，13px / 500
- 次按钮：无边框文字，悬停显示底色
- 描边按钮只用于危险操作或弹层内

**如何美观而不加信息**：靠留白、字号与字重层级、对齐、单一强调色和背景分层来区分区域，而不是靠边框。阴影只用在输入框和浮层这两处。

## 四、仍担心的一处

去边框会降低控件的可发现性。所以我保留输入框和参考行操作的悬停底色作为可点提示，第5轮看图时要重点核对这一点。另外，左栏 36px 单行会截断较长的中文标题，需要靠悬停 title 加主区完整标题来弥补，这一点我仍不完全放心。
