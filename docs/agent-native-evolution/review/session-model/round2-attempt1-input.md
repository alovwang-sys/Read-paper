## 真正的错误

问题不在“只显示一条”，而在于把**对话当成了成果的附属品**。研究的价值在推理过程，成果只是其中某一轮的产出。具体有三处错：

1. **主次颠倒**：主区放成果，对话被压成底部一条，进入了解决不了上下文的局面。

3. **名实不符**：引擎切换会跳转会话；“续接”实际是摘要重放，却当原生 session 呈现。

## 模型

```
Research {资料, 共享文稿/白板, Artifact[]}
 └ Conversation {title自动生成, lastActiveAt, engine, continuity: native|replayed}
    └ Turn(AIRequest) {prompt, response, contextUsed, producedArtifactIds[]}
Artifact {researchId, originRequestId}
```

- 成果归 Research 共享，通过 `originRequestId` 回溯到产生它的那一轮，而不是归属某个会话。

- 现有的 `Session` 类型改名为 `WorkspaceState`，避免和会话混淆。
