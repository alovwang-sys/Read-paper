## D. 可点击原型必须实现的 10 个动作

1. **在空研究里输入目标并拖入 PDF**：输入框里出现"2 份 PDF"标签，输入框不移动。
2. **发送**：输入框下沉；目标标题和活动行"读 2/4 篇 · p7"出现；发送按钮变成停止。
3. **比较表逐行写入**：表头显示覆盖情况；Agent 写的行带细边。
4. **追问"第 3 行为什么这样分"**：短答不超过 6 行；滚动表格时折叠成一行，下次发送前不消失。
5. **点引用 [2]**：参考区打开并高亮原句；第 3 行仍然选中，写入标签不变。
6. **点"在中央深读"**：PDF 进入主区，出现返回条；⌥← 回到原来的滚动位置。
7. **深读期间任务完成**：画面不切换；活动行显示"已新建…· 打开"，左栏出现圆点。
8. **点"第 7 轮 ▸"**：参考区换成全文对话；再点引用时由来源替换，头部能切回对话。
9. **手改一行后让 Agent 重写**：改过的那一行显示行内建议（接受 / 忽略），不会被覆盖。
10. **把窗口拖到 1024 宽，再导出 Markdown**：左栏收起，参考区把主区推窄，输入框始终可见；导出文件的文首出现状态说明行。

## 先修正三处规则

- **a. 来源和证据分开标，编辑不等于核实。** 每段或每行有两个独立属性：作者（Agent／你／你改过）和依据（引用 [n] 旁用文字标"全文""摘要""无出处"）。用户手改只会把作者变成"你改过"，依据状态不变。界面不设"已核实"状态。
- **b. 删掉"写入：比较表"标签。** 输入框里最多只有一个可清除的焦点标签「围绕：…」，而且只有显式点"问"才会生成。修改目标只在执行修改时出现在活动行，例如"正在修改 比较表 第2–5行"。
- **c. 手绘线永远只是画的线。** 老箭头不升级，样式不改。Agent 读到带标签的连线时，只能把它引述为"你画的假设 A→B（未论证）"，不能当作依据。

## 8 个场景

**1. 无 PDF，直接要求找文献**
- 看到：主区中央只有一个输入框，提示"要研究什么？直接说，或拖入 PDF"。这时还没有创建研究。
- 做什么：输入"帮我找近三年的检索噪声研究"，回车。
- 系统反应：
  - 发送时才建研究。原话作为目标行，左栏自动命名为"检索噪声（2023–2026）"，点名称可改。
  - 公开检索直接执行。只在第一次时，活动行显示一行"使用公开学术检索"，之后不再提示，也不询问。
  - 主区生成"候选文献"表，逐行出现。每行写明"全文可读 / 仅摘要 / 无法获取"。仅摘要的行可以把 PDF 直接拖到该行补全文。
  - 短答先出："找到 18 篇，11 篇有全文，初分 4 组"。
- 继续：输入框在底部，焦点在输入框。候选还不算留存。

**2. 重开研究：停在 p7 有草稿，另一任务同时完成**
- 看到：主区恢复到 PDF 第 7 页原滚动位置。输入框恢复草稿，光标在末尾，焦点标签原样。
- 系统反应：任务完成只体现在活动行"《相关性分组》已完成 · 打开"和左栏圆点。焦点不跳走，画面不切换，草稿不改。其他研究完成的任务只在左栏亮点。
- 点"打开"：新对象成为主区标签，顶部返回条"← PDF p7"。草稿和标签都不变。

**3. 编辑第 2 项途中点引用、深读、选原文**
- 编辑：在比较表第 2 项里直接打字，内容即时保存为"你改过"，不需要发送。
- 点引用、点深读：参考区或主区换内容，出现返回条。第 2 项的光标位置被记住，输入框不动。
- 选原文后点"问这段"：
  - 输入框里的草稿文字原样保留。
  - 标签从「围绕：比较第2项」换成「围绕：《X》p7 选段」。
  - ⌘Z 可换回原标签，× 则清除标签。
  - 光标放到草稿末尾，不自动发送。
- 继续：⌥← 回到第 2 项原光标处。

**4. 先问"为什么这样分"，再要求改**
- 系统反应：问题一律只出短答，不碰文稿，不建卡片。
- 说"改成按数据集比较"后：
  - 活动行显示"正在修改 比较表 · 6 行"。
  - 改动直接落在表里，改过的地方显示差异。
  - 活动行末尾有"撤销"，⌘Z 效果相同。
- 意图含糊时（如"能不能按数据集比？"）：先回答，短答末尾附一个"按此修改比较表"按钮，由用户点击才执行。
- 原则：宁可少动，不可误动。

**5. 找上周的旧卡片或旧绘图**
- 入口：左栏顶部搜索框，⌘K 聚焦。左栏原来的"资料"改名为"全部"。
- 做什么：输入关键词，结果按"PDF / 文稿 / 卡片 / 绘图 / 对话"分组，每条注明所属研究和日期。绘图带缩略图。
- 系统反应：回车后在参考区打开，主区不动。绘图会定位到画布的对应区域。
- 返回：关闭参考区即可。如需在中央打开，会出现返回条。

**6. "把这 3 篇留下"**
- 对象：先看选中的行；没有选中就取上一条短答列出的 3 篇。活动行会写出标题，选错一眼可见。
- 系统反应：一次执行，活动行一行汇总："已留在本研究 3 篇：1 篇新入库（仅摘要）；1 篇已在库，未重复；1 篇与《旧研究》共用同一份，未带入其批注 · 撤销"。点开可看逐条明细。
- 规则：
  - 去重按 DOI 或文件指纹做。
  - "留下"只是关联到本研究。
  - 撤销只解除本次关联，新入库的条目在别处没被用到时才删除。

**7. 手改段落后 Agent 更新全文**
- 系统反应：
  - 用户没碰过的段落直接改写，并显示差异。
  - 用户手改过的段落不覆盖，段下给出行内建议，带"采用 / 忽略"。
- 三个动作的边界：
  - 采用：作者变回 Agent，依据换成建议所附的引用。用户原文留在历史里。
  - 忽略：建议消失，但仍可在对话记录里找到。
  - 撤销：一步撤回本次 Agent 对所有段落的直接改写。
- 无论哪个动作，都不会出现"已核实"。

**8. 1024 宽，参考区、长回答、多行输入同时存在，又报错重试**
- 布局：左栏 48 + 参考区 340 + 主区约 636。
- 空间不够时按顺序折叠：
  1. 先收活动步骤；
  2. 再把短答收成一行（"你：…… · 展开"）；
  3. 主区窄于 560 时，参考区改为浮层。
- 不折叠的部分：输入框最多 6 行，超出在框内滚动；发送和停止按钮永远可见。
- 报错：短答位置只占一行，"失败：检索超时（已完成 2/4 步）· 重试"。
- 重试：用记录里的原消息从失败步骤续跑。输入框里的新草稿不动，焦点留在输入框。
- 键盘：
  - Esc 依次关浮层，再收起展开的回答，永不清空输入。
  - ⌥← 走返回条。
- 记录：每轮都写进对话记录，左侧"第 N 轮 ▸"和 ⌘K 都能找到。长回答永远是回答，只有点"存为文稿/卡片"或明确下指令，才会成为成果。

## 默认界面真正删除的三项

1. 三处保存状态提示（"未保存 / 绘图待保存 / 有未保存修改"）。改为全部自动保存，只在保存失败时出现。
2. "把所选文字作为问题"模态框，包括标题、描述和三个按钮。
3. 输入框下的"材料 N / 历史 N 轮 / 字符估计"计数行。

| 新研究 | “你想研究什么？”、唯一输入与可添加资料的入口 | 直接描述目标；不先填写项目表单、选择卡片或画布类型 |

| 有资料，要求比较 | 一行实际进展，中央逐步形成可编辑初稿 | Agent 自行查找和读页，用户不逐项勾选上下文或点生成卡片 |
| 只问解释 | 输入上方的简短问答，可展开或收起 | 不强制建卡、写文稿或修改现有成果；完整问答始终能从“对话记录”找到 |
| 明确要求整理或修改 | 中央留下持久成果，对话只交代改了什么 | 长正文不在聊天和文稿中重复展示，不再要求复制保存和摆放 |
| 回到已有研究 | 上次成果或原文位置、未发送输入 | 输入与原来提问对象恢复；迟到结果只显示完成提示，不抢主画面 |

研究名称可以从首个目标拟定，随时直接修改；名称不作为切换研究身份或覆盖资料的依据。普通问答、修改和新的研究方向由用户意图区分，不能仅按回答长短决定是否建立成果。

## 查看与提问有不同的触发

点引用、查看资料或翻页只改变正在看的内容，不改变已经准备的问题及其修改目标。用户选择“围绕这里追问”时，才在唯一输入上方显示一条可清除的焦点提示，如“围绕比较第 2 项”。不把阅读位置、写入目标、来源范围各铺成一排常驻标签。

未发送文字必须保留。用户显式改为围绕另一处提问时，应清楚显示对象变化，并能撤销这次切换；普通浏览不会触发切换。提交后研究、目标和取回材料绑定该次请求，随后查看其他内容不改写已提交范围。

Agent 需要修改现有内容时说明实际目标与变化。解释性问题只产生回答；用户明确要求重分组、改写或补证据后才执行相应修改。歧义会影响既有内容时，先用简短问题澄清。

## 原文和对话的去向

| 触发 | 出现位置 | 返回与保留 |
| --- | --- | --- |
| 点一条引用 | 唯一参考区显示来源、页码与原句 | 关闭后原成果与选区保持；输入及提问对象不变 |
| 点“阅读全文” | 原文占主区，定位到对应页 | 固定显示“返回比较结果·第 2 项”；恢复原滚动、白板视口与选区 |
| 在原文里明确问一段 | 复用唯一输入，显示这段原文的焦点 | 保留现有输入，明确告知焦点变化；不产生第二个聊天框 |
| 点“对话记录” | 同一参考区显示完整问答 | 输入不移动；来源替换对话时可回到先前记录位置 |
| 点“资料”或查找 | 同一参考区浏览本研究内容 | 不重置研究身份；旧笔记、卡片、白板、文稿和论文都能找到 |
| 点总资料库 | 同一参考区显示跨研究内容及所属范围 | 只浏览不自动加入研究；一次“采用这些资料”完成需要的去重与关联 |

参考区不叠加第二个抽屉。它的标题说明当前看的是什么，关闭和返回位置固定。“对话记录”入口保持可见，不只提供快捷键；短答收起后仍能恢复。

## 一个画布承载内容和图形

卡片、论文、自由文字、形状和箭头在同一画布共存。画布出现时才展示相关选择、添加、文字、形状、画笔和连接工具；阅读和写作界面不显示这些工具。没有“卡片布局／绘图”的全局切换。

选卡片即可打开正文、查看来源或围绕它研究；调整位置和直接改字继续支持。Agent 在用户明确要求时整理画布；不把每次拖动、改颜色或画线变成模型请求。

自由箭头保留原样，不因统一画布强制改成虚线、附加“手绘”标签或升级为已证实论证。关系说明属于用户判断或 Agent 提议；原文引用与论断是否获得支持继续分开核查。旧绘图、摆放、关系和来源必须完整可达后，才撤下旧模式入口。

## 草稿 修改与恢复

初稿直接留在工作面并自动保存，明确标注来源与尚未核查的依据。手工编辑不等于核实通过，也不抹掉 AI 出处。用户可以继续修改、保留使用的资料或导出，不强制点击“采纳为定稿”完成一次研究。

Agent 修改自己尚未被用户改过的草稿，可直接显示并保留回执；碰到用户已经修改的内容，在原处提出差异建议，用户选择采用或保留。采用后可撤销本次仍可安全撤销的修改，不能抹掉后来人工编辑的内容。

停止保留已经完成的部分；重试沿用原目标与已有结果，不重复入库或新建同一成果。刷新后的未完成运行需要明确恢复，不能盲目重放操作。尚未实现的后台继续、自动全文获取与引用核实，不作为界面上的完成状态。

## 从默认界面真正撤下的内容

1. 资料、摘录、卡片、白板、文稿作为必须依次选择的一级研究步骤；替换为正在做的内容、最近与统一查找。
2. 摘录／卡片／AI 的永久右栏模式行，以及重复的聊天标题和助手状态工具栏。
3. “问 Agent／找已有依据／找文献”三条需要用户分别调度的主路径；由研究目标决定取用方式，手动浏览仍可直接进行。
4. 每条候选的加入讨论、入库、放到问题旁，以及回答的生成卡片、确认、保存、摆放连续链；按明确意图批量完成。
5. 输入区常驻的模型、推理强度、技能、Plan、历史轮次与字符预算工具排；运行配置留在设置，范围与实际来源可查看。
6. 卡片与绘图的互斥工作面；统一时完整保留旧内容，不能只隐藏一个模式。

不把这些入口原封不动塞进一个“更多”菜单。日常动作改由委托执行；需要直接浏览或编辑时，对象本身提供对应操作。
