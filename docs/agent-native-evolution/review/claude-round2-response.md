# 第二轮回应：接受大部分反驳，补三个条件

## A. 接受与拒绝

8 条反驳我基本接受。有几处我补了条件，因为不补的话方案会出漏洞。

- **接受 1。** "画布主导、阅读器降级、文稿唯一输出"确实过窄。修订后的默认布局：
  - **中央是当前任务的成果**，本切片就是比较表。画布、文稿、文献集合是同级的成果形态，不是模式。
  - **右侧是唯一参考位**，承载原文定位、材料详情和运行回执。
  - **Agent 输入只有一个**，固定在中央底部。
  - 点引用时，参考位打开到该页并高亮。选"深读"时，同一个阅读器展开到中央；返回后回到原成果和原滚动位置。
  - 不新增成果中心，也不新增标签体系。
- **接受 2**，首切片不做自动下载，我也不认为首次必须做。但要补一个条件：只读已导入的 PDF，会让"覆盖不全"成为常态。所以"几篇读了原文、几篇仅元数据"必须写在结果本身的表头，不能只藏在回执里，否则比较表会误导人。
- **接受 3**，并收回"拖出即采纳"。采纳必须是显式的一句话或一个动作。另补一条你没提的规则：用户改过的格子，所有权转给用户。Agent 之后再改这一格必须走差异确认；没被改过的草稿仍可整批撤销。
- **接受 4**，删去"三次判断"。但停下的条件要分两类：
  - 权限扩大、超出范围：由程序强制拦截，不靠模型自觉。
  - 关键歧义：属于模型行为，只能测量，不能保证。
- **接受 5**，第一轮确实自相矛盾。补一条：切换模型要重新显示委托说明。
- **接受 6、7、8。** 画布统一不进首切片。现有的旧绘图和自由箭头完全不动。

## B. 实际交互

场景：研究"RAG 检索噪声"，已导入 6 篇 PDF（其中 4 篇文本就绪），另有 3 条 OpenAlex 候选。

1. 用户输入："比较这些论文对检索噪声的定义、度量和结论。"
2. 首次委托只显示一行："将在本研究范围内取回必要片段，由 X 模型处理。"用户直接继续。
3. Agent 自行决定步骤：查本研究、读 4 篇的相关页、定位原句、写表。参考位滚动显示回执，用户不用选材料。
4. 中央出现比较表（草稿样式）。表头写明"4 篇读原文 / 2 篇仅摘要 / 3 条候选未读"。原文格带页码引用；摘要格标"据摘要"，没有页码。
5. 用户点开论文 B 的引用，右侧跳到第 7 页高亮。用户发现那是相关工作段落而不是 B 的结论，于是直接在格子里改写。
6. 用户说："度量按数据集分开；那 3 条候选收进资料库。"
   - Agent 重写度量列。B 那一格用户改过，所以显示为待确认的差异。
   - 3 条候选沿用现有批次一次入库，回执列出这 3 条，可撤销。
7. 中途刷新：已写入的表格还在，入库不会重复。

## C. 减法清单

1. **移除主路径**：每轮勾选"加入讨论"。改为研究范围、首次委托说明和回执。快照数据保留。
2. **移除主路径**：AI 卡片多步确认（确认、建卡、摆放）。改为草稿直接显示，可整批撤销。
3. **移除主路径**：独立的"找已有依据"按钮。这个能力改由工具提供。
4. **合并**：候选逐条的 3 个动作，合并为一句话或一个批量动作，复用候选批次。
5. **合并**：右侧 3 种模式，合并为一个参考位。
6. **按需保留**：助手、模型、权限、字符预算、历史轮次、检索条件、版本比较、快照详情。
7. **暂不动**：左侧 6 个入口、绘图与卡片切换、两种连线。等画布逐步统一时再处理，届时数据双轨保留，不自动升级关系。
8. **不采纳**：workbench-redesign 的五入口方案。它只是菜单整理，不能当作这次转型。

## D. 最小闭环

闭环：比较问题 → Agent 检索并读取已导入的文本就绪 PDF → 真实原文片段 → 可编辑的比较草稿留在研究中 → 一句话修改 → 批量入库。

**真正新增的工程能力**，其余全部复用：

1. **一个运行时的结构化工具桥**，与 UI 共用服务层。工具包括 `search_research`、`read_pages`、`locate_quote`、`write_draft`（写入 CardDraft 组）、`import_candidates`（复用候选批次）。Claude runtime 目前的 tools 为空，需要单独实现，不能假定 CLI 自带。
2. **研究范围的程序化执行**：工具层直接拒绝范围外读取。原生助手的目录权限照实显示为"目录可读"。
3. **确定性的原句匹配器**：输出唯一命中、多处命中、模糊、无文本层四种结果。
4. **CardDraft 组的表格视图**。若 CardDraft 承载不了维度字段，这将是唯一的数据变更，需要先确认。
5. **回执与整批撤销**：基于现有变更历史，加上入库幂等键。

**验收标准：**

1. [确定性] 每条原文引用都有资产 id、hash、页码和命中片段，且在该页唯一命中。多处命中、模糊匹配、扫描件一律标出，不得写成原文引用。没有文本就绪 PDF 的论文，结果中不出现页码。
2. [确定性] 范围外读取被拒绝并记入回执。切换模型会重新触发委托说明。
3. [确定性] 刷新或断线后，已写草稿仍在；重试不会重复入库；整批撤销后恢复原状，用户内容没有变化。
4. [确定性] 用户改过的格子，Agent 永远不会静默覆盖；删除或重排用户对象必须先确认。
5. [模型行为] 用 10 个以上不同的真实问题测试，统计三项：用户无需手动选材料、建卡就完成的比例；工具调用轨迹是否随问题变化；无谓停顿的次数。只报告数据，不承诺数值。
6. [模型 + 人工] 由独立盲审抽样核查"引文是否支持格子里的论断"，报告支持率。阈值在建立基线后再定，不写 100%。
7. [模型行为] 一句话修改只改动了目标列或目标格的比例。
