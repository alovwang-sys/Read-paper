## 确定的交互方向

**框选自己画的一部分 → 问 Agent → 底部现有输入出现局部预览 → 写一句话并发送。**

不强制转卡片，不新建聊天框，不跳回经典工作台。仅选图形、箭头、笔迹或图片时也应有同一个入口。操作先准备附件，不自动发出请求；保留原输入，输入旁继续显示发送到哪个会话。选中和普通浏览本身不改变已准备的上下文。

例如画“检索 → 筛选 → 生成”，框选后可以直接问：“这个流程哪里可能放大噪声？”Agent 看到用户明确选择的画面与关系，回答出现在当前会话。问图属于只读分析，不继承上一次文稿的修改目标，也不默认修改原图。需要沉淀成果时继续复用现有文稿，不要求复制到另一套资料库。

“按这张图找相关论文”仍可从同一个输入表达，不再加一组常驻按钮。检索返回候选，明确收录后才关联研究；不会把搜索到的摘要说成已读全文。

## 最低可接受的内容与范围

看图必须真的发送图片，不能把几个文字标签包装成“理解了你的笔迹”。同一次冻结快照需要包含：

- **局部图片**：只渲染已确认选区中的元素。不能截整块 DOM 区域，把未选择但碰巧位于包围框里的内容一并上传。
- **结构快照**：所选文字、形状及位置、箭头方向／标签、对应元素 ID。两端均在选区内的连接完整附送；跨界端点只标“选区外”，不沿箭头递归取其他节点或正文。无标签箭头只是用户画的方向，不自动解释为因果、支持或反驳。
- **所选卡片的文本快照**：正文、ID 与位置映射。Excalidraw 原生导出不包含 React 卡片实时正文，不能只发一张看似完整、实际漏掉卡片内容的图片，也不能只发模型无法取回正文的 ID。预览应分别展示真正发送的图和文本。

建议首版预算：一张 PNG，最长边 2048px、压缩后不超过 2MiB；选区结构最多 100 个元素；图中文字和选中卡片正文合计不超过 12,000 字符。这些是**待真实小字图／笔迹验证的设计值**，不是已经生效的限制。超限提示缩小选区或精简，不默默漏元素、截断正文。

本轮发现一个必须同时修改的范围问题：`collectResearchSources()` 当前不论 focus 为何，都会准备研究前八份 PDF、每份前 24 页、总计最多 160,000 字符。问图应默认 `sources=[]`，不能沿用这条路径后声称“只发所选图”。用户明确要求查本研究依据时，再授权限定的论文范围；公开找文献只发送检索词和条件，不把图片或整份笔记上传给检索站。

当前会话历史与附件分开记录：继续沿用同会话最近六轮／12,000 字符预算，不读取其他会话。历史可能包含先前回答的引文，因此范围回执应说“未追加论文原文”，不能在带历史时声称完全没有任何论文相关文字。新建会话可从空历史开始。历史里的引用不自动成为本轮可引用原文。

附件和提交绑定原研究、原会话、选中元素与不可变快照 hash。保存实际发送的图／结构，不能用最后已保存的白板 hash 冒充尚未保存的新画面。重试使用原快照；图后来被修改或删掉，历史问题仍能打开当时的内容。切换会话后，迟到答复只进入原会话，不抢主区或覆盖其他输入。

## 助手能力与检索

图片支持必须按实际适配器检测并验证。支持图片的连接才发送 PNG；不支持时保留附件并明确提示，由用户选择经过核对的文字／结构内容，或换支持的连接。仅发文字／结构的回答必须说明没有看图；纯笔迹无有效文字时，不能用空结构假装给出视觉分析。

建议分两个可验收切片：

1. **直接问图**：选区快照、真实图片通路、当前会话、局部范围、失败／停止／重试及历史恢复。没有通过真实看图验收前，不将入口标成已支持。
2. **根据图检索论文**：给研究运行接入受控 OpenAlex 工具，复用现有检索、去重、候选和收录服务，解开其与旧 `boardResearch` UI 的绑定。`search_sources` 目前只查本轮本地 PDF，并非联网文献检索。

Claude 建议将检索放到第二切片，避免把图片理解和新增外部工具混成一次验收；采纳这个分工。没有采纳“每次检索都必须再确认”的额外步骤：用户明确要求检索时按授权执行，展示实际检索词并允许编辑重搜；仅在私有代号等无法合理确定公开查询含义时澄清。

图中文字、笔迹与连线作为“用户的想法”，与论文证据分开。引用论文仍需真实读取原文并校验来源；不为用户自绘图伪造 PDF 页码。纯问答不改画布；通用改图 Agent 不在本轮方案范围，将来明确要求的小范围可撤销修改也不应一律再走确认表单。

## 实现与验收边界

复用当前工作台、会话、上下文入口和资产保存，不新建全局知识实体或 Agent 平台。主要改动将涉及绘图选区及导出、当前会话待发送附件、请求／服务端白名单、运行时真实图像输入与能力声明，以及备份、重试和引用校验。不能把新附件硬塞回会触发经典面板的旧 `boardResearch` 路径。

实施前必须覆盖：

1. 实际载荷与预览一致；未选节点、未授权 PDF、其他会话的独有内容不出现在请求里。
2. 真实模型收到局部图片，能解释含图中文字及手绘关系；识别不清时明确表达疑问。仅序列化结构的模拟测试不算通过看图验收。
3. 会话切换、刷新、停止、失败与重试保留附件和原归属；问图不会改写遗留文稿目标。
4. 卡片正文没有因导出丢失，原始图与共享卡片不被问答操作改动，快照纳入保存与备份。
5. 图片不支持、空选区、图像／文字超限、旧元素已删除都有清楚状态，输入保留。
6. 后续检索单独验真实 OpenAlex、范围与出站查询、去重、候选收录和引用能力；不把问图通过当作检索通过。
