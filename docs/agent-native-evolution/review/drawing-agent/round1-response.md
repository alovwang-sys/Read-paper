## 建议

**交互**
选中任意部分后，浮动条只放一个"问 Agent"。点击后，选区作为引用块贴进底部唯一输入框，归属当前会话；用户补一句话再发送。不强制转卡片，也不跳到经典面板。"继续研究"只是同一句输入里的意图，不另设按钮或表单。

**分阶段接入**
1. **现在就能做**：把选区序列化成结构文本。
   - 文字和图形标签直接带上。
   - 已绑定的箭头写成"用户标注：A →(标签) B"。
   - 关联的卡片或 PDF 只带 ID 和标题。
   - 图片和笔迹只提示"含 N 项未解析"，不假装看懂。
2. **之后再做**：研究运行接口新增选区快照字段，按适配器能力开启。Claude Code 目前 images=false，界面应如实标注"当前模型未接图"。

**上下文**
- 带：选区结构、关联卡片引用、本会话的局部目标。
- 不自动带：整张画布、未选中的邻近元素、其他会话历史、图片和笔迹像素。
- 箭头和图中文字一律标为"用户的想法或假设"，不当作论证或原文依据。

**结果与权限**
- 回答留在中间的当前会话里。引用必须经过真实读页验证。
- 改图只给预览，用户确认后才写入画布。
- 收录资料走旧局部研究里的 OpenAlex 候选确认。原生新研究工具还没联网，应明说"暂不能检索"。

**最重要的反对意见**
选区默认进入"当前会话"，但用户画图时，当前会话可能在讨论别的话题，会污染局部目标和历史。缓解办法：引用块上显示目标会话名，并支持一键改投到其他会话，不另开侧栏。
