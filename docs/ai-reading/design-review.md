# AI 阅读设计检查记录

日期：2026 年 10 月 16 日。检查对象：产品需求、UX 规格、开发计划与静态交互原型。结论：设计主线与分期可进入开发；本记录不表示生产功能或真实模型验收通过。

## 文档一致性

已对照当前源码和既有参考图检查已有能力，保留“演示 AI”的事实说明。产品需求 PR01–PR10、UX 状态 S01–S09 和开发任务 AR0–AR8 已互相对应；开发计划包含 22 项待执行验收场景。

交叉评审收敛了以下规则：

- R1 是文字阅读闭环；R2 区域阅读独立排期。图像模型试验不阻断 R1。
- 两期选区均以单页为单位，跨页逐页添加；不承诺双栏自动重排。
- 原始问答与可编辑卡片草稿分离。重新生成仅针对最新轮，新成功版用于后续默认历史，旧版供卡片回查。
- 停止、断流与未通过引用校验的回答不能伪装为完整可引用成果；无效引用可以通过保留对话来源的人工草稿修复。
- 文字证据保留摘录，区域证据保留图片资产、坐标、页码和说明。移除本轮证据不会擦去历史消息中的原文。
- 结论使用卡片时保存使用时的来源快照，后续编辑卡片不反向改写已使用的出处。
- Enter 换行，Ctrl/⌘+Enter 发送，中文输入法组合输入不触发发送。

## 实际原型检查

通过 Codex 应用浏览器访问独立静态预览。所有数据来自自制样例，回答和修订均为预设内容；原型只在内存保存，不调用模型或读写生产资料。

| 路径 | 实际观察 |
| --- | --- |
| 选取示例段落 → 向 AI 提问 | 材料加入输入区，显示文档与 PDF 第 3 页；未自动发送 |
| 选取示例段落 → 解释这段 | 默认问题立即模拟发送，回答完成后出现知识点整理入口 |
| 连续追问 | 第二轮显示包含 1 轮前序问答；完成后显示 2 轮。此项只验证交互，真实多轮 payload 待开发验收 |
| 回答选片段 → 整理 | 可按段选择，生成有独立标题、正文与双来源的卡片草稿 |
| 修改标题 → AI 修订 → 应用修改 | 修订先作为候选展示，应用后替换草稿，保留恢复上一版入口 |
| 模拟保存失败 → 重试 | 失败时内容保留、按钮变为重试；重试后卡片数量为 1 |
| 卡片 → 论文依据 | 右侧展示第 3 页摘录与高亮示意，主区继续显示原阅读任务 |
| 卡片 → 相关对话 | 显示原问题、创建时回答片段、高亮和实际范围摘要，可展开完整回答 |
| 新建会话 → 输入 → 历史 → 重开 | 新会话没有旧材料与历史；未发送输入在该页面内切换后保留 |
| 区域模式 → 框选示例图 → 加入材料 | 显示区域边框和区域材料标签；这只是 R2 示意，不是 PDF 裁图验收 |
| 模拟断流 → 按原范围重试 | 部分回答显示未完成，不进入默认历史；重试后恢复完成的模拟回答 |
| 1024px 抽屉 → Esc → 重新打开 | 可关闭并回到主区，重新打开后继续访问消息和历史；折叠导航仍有可读名称 |

检查中修复了原型内容宿主与图标重名、图标尺寸未约束、网格被长内容撑高和折叠导航缺少名称的问题。最终脚本语法与静态 ID 唯一性检查通过；静态检查确认没有网络请求或生产存储访问。

## 布局与截图

1440×900 与 1280×800 检查三栏，1024×800 检查导航折叠与覆盖抽屉。最终 1440×900 下 app、主区和右栏均为 868px 高，输入区底部为 900px，app 没有被焦点操作滚离顶部；1024×800 下输入区底部为 800px、文档宽度为 1024px，无整页横向溢出。各区长内容在自己的区域滚动。

## 未验证范围

本轮没有修改生产源码、依赖或数据库，没有重跑生产单元测试、构建和 E2E。真实模型、多轮请求内容、实际 PDF 拖选与裁图、引用校验、持久化恢复、跨研究隔离、导出和生产辅助功能验收，均按开发计划执行。

本轮只核对桌面三个目标尺寸与部分键盘路径，未完成移动端、屏幕阅读器、200% 缩放或全部浏览器兼容性验收。原型中的恢复提示只是目标体验，刷新原型会重置。
