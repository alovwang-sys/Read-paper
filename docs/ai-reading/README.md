# AI 阅读与知识卡片设计入口

日期：2026 年 10 月 16 日。产品设计基线 v0.2；文字闭环与区域问答核心路径已实现。实际结果以[实现与验收记录](../verification/ai-reading/README.md)为准。

本轮围绕“选取论文材料 → 连续对话 → AI 整理知识卡片 → 用户修改确认 → 回查论文和对话”完成规划与实现。应用现已接入用户指定的真实模型，同时保留明确选择的演示模式。下面的原型仍是设计评审材料，实际产品请按[项目 README](../../README.md)启动。

| 文档 | 阅读用途 |
| --- | --- |
| [产品需求](requirements.md) | 用户任务、两期范围、PR01–PR10 行为与验收、来源和数据规则 |
| [UX 交互设计](ux-design.md) | 页面结构、关键路径、状态、尺寸、键盘与恢复行为 |
| [开发计划](development-plan.md) | AR0–AR8 依赖、模块所有权、共享契约、实施清单和验收矩阵 |
| [可点击交互原型](prototype.html) | 预演选区问答、整理卡片、编辑保存、历史与双来源回查 |

先交付 R1 文字阅读的完整闭环；R2 完成图表、公式和扫描页的区域问答。原型中的回答与数据为模拟内容，仅保存在该页面内存，刷新会重置；不调用模型，不写入应用资料库。

可从项目根目录启动独立设计预览：

```sh
python3 -m http.server 4180 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:4180/docs/ai-reading/prototype.html>。这只服务静态设计文件；应用的启动方式仍见[项目 README](../../README.md)。

总产品方向见[产品规划](../product-plan.md)，原有批次和本轮入口见[开发任务清单](../agent-backlog.md)。设计预览与检查记录见[设计检查记录](design-review.md)。
