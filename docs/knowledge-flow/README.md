# 知识链路设计入口

日期：2026 年 10 月 17 日。设计基线 v2，本轮实现与验证见[验收记录](../verification/knowledge-flow/README.md)。

后续调整见[研究工作台导航与笔记整合方案](workbench-redesign.md)：汇总用户对导航层级、摘录与卡片、资料库切换和右侧面板的反馈，提出平铺五入口、统一卡片、标注归回资料及资料库保留研究环境的整体方案。状态为提案，尚未实施；下列 v2 文档继续描述当前基线。

```sh
python3 -m http.server 4180 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:4180/docs/knowledge-flow/prototype.html>。应用本身的启动方式见[项目 README](../../README.md)。
