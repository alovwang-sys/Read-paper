## 基线与边界

旧版界面确认应用内已保存、回答完成、无草稿。菜单 Quit、目录保存重试均显示“目录文件尚未保存：本机 Agent 连接失败”；窗口保留。SIGTERM 等待 10 秒后旧主进程及其 Helper 仍存在，安装脚本 exit 1 拒绝交换应用。原应用与新包此时均未被替换。

`installDesktopLifecycle → flushProjectFiles → directoryRequest(sync) → server projects/files`；客户端保存失败经 `close-prepared(error)` 只提供返回入口。服务通用错误处理将无 status 的底层异常泛化为 Agent 连接错误；具体 errno 未取得。目录清单中 14 文件 hash/size 一致，无事务残留或只读标记。这不能排除旧进程自身的系统目录权限。

## 维护处理与验证

复制完整 userData 至本机私有备份；23 个 IndexedDB/Local Storage 文件在源前后两次读取及副本间 hash 一致。SIGTERM 后存储发生正常文件更替，第一次即时核验拒绝继续；重新备份并核验稳定，再仅强制结束已核实、无在途工作的旧主进程，Helper 自行退出。没有通过破坏渲染或服务制造退出超时。

随后原子交换应用，保留旧应用供回滚；新包启动、保存状态、原研究、12 条问题及 PDF 两处位置恢复，实际全屏与可见退出入口验证通过。旧应用与旧安装器移至可恢复废纸篓；数据备份保留。强制维护退出不能称正常 Quit，也不等同修复目录同步。
